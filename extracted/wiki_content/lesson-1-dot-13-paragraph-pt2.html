Now that we are familiar with most of the HTML elements. Let's start creating the Big Cats page we saw in the beginning. 

INSTRUCTIONS:

  1. Create a new folder called big_cats inside your moringa_pre-prep folder
  2. Inside the big_cats folder, create an html file called index.html.
  3. Using your VS Code, add the following in your index.html file
<!DOCTYPE html>
<html>
  <head>
    <title>Big Cats</title>
  </head>
  <body>
    <h1>Big Cats</h1>
    <h2>Lions</h2>
    <p>Here are some fun facts about lions.</p>
    <h2>Tigers</h2>
    <p>Here are some fun facts about tigers.</p>
  </body>
</html>

You'll notice that we have used all the html elements we have learnt so far. Our page is coming along nicely.

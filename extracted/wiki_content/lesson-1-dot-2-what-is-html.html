Introduction:

In the last lesson, we vaguely mentioned HTML. It's time to expound more on HTML and what it entails. 

HTML stands for HyperText Markup Language. HyperText just means we can link to other web pages. Markup means it gives extra instructions to the content (using tags) to make it more than just plain text.
Every website is created with HTML. It provides the structure of a web page.
Consider the following piece of code.
<!DOCTYPE html>
<html>
    <head>
        <title>Lesson 1</title>
    </head>
    <body>
        <h1>Lesson 1</h1>
        <h2>Intro to HTML</h2>
        <p>I'm learning HTML!</p>
    </body>
</html>

In your terminal, navigate to the Documents folder and create a folder/directory called html_projects.  (Note: We'll put all the  HTML and css projects that we'll create in this folder.)

$ cd Documents

$ mkdir moringa_pre-prep_projects

$ cd moringa_pre-prep_projects

Inside the moringa_pre-prep_projects directory, create yet another folder/directory called html-demo-page. 

$ mkdir html-demo-page

$ cd html-demo-page

Inside this folder create a file and name it index.html.

$ touch index.html

Now open the file in vscode using the following command:

$ code .

The $ code command tells the computer to open anything that follows it in vs code editor. The . means current directory, so the entire directory/folder should open up in Atom.

Type the html code above in the index.html file

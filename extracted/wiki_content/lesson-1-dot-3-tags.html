HTML is structured by tags. A tag is written between angle brackets, like <title>.

  

Let's use the previous piece of code as an example:

<!DOCTYPE html>
<html>
    <head>
        <title>Lesson 1</title>
    </head>
    <body>
        <h1>Lesson 1</h1>
        <h2>Intro to HTML</h2>
        <p>I'm learning HTML!</p>
    </body>
</html>
You'll notice each opening tag has a corresponding closing tag, for example <title> and </title>.
The opening tag, closing tag, and all the content between them together make up an element, so <title>Lesson 1</title> is called the title element.

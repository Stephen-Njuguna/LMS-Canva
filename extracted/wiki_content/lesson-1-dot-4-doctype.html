It's time to get coding. Let's start building a website from a blank document.
 
DOCTYPE is a special tag that tells the web browser what language to interpret this document in. We're writing HTML, so we'll start with <!DOCTYPE html>.
INSTRUCTIONS:
  1. Inside the moringa_pre-prep_projects folder, create a file called my_first_html_page.html. Notice that we have added a .html extension at the end of our file name.  That tells the browser that the file is an html file. Remember to include the .html extension every time you create and name your html files in the future.
  2. Open the file using your favourite code editor. In our case, we'll use Visual Studio Code. 
  3. Write <!DOCTYPE html> in the code editor, then move on to the next lesson.

Introduction

We can also style direct descendants (children) of other elements. In fact, we can even style direct descendants of other direct descendants and so on...To do this, we use a right angle bracket (>) like this:

 div > p {
          border: 2px solid red;
          padding: 5px;
  }

Instructions:

  • Create a new folder and name it direct_descendant_selector. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="styles.css">
        <title></title>
    </head>
    <body>
        <div id="parent">
            <h1>CSS selectors</h1>
            <p>The div above me is my parent. The h1 next to me is my sibling. Sometimes I call him bro.</p>
        </div>
        <div id="other_parent">
            <p>In this family, we have a div that is our ancestor. He's really awesome. Then there's me. And my child who is a span. You can call him Bob. <span>Please don't call me Bob. Span is fine.</span></p>
        </div>
    </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • Style the p element, that is the direct child of the div element with the id "parent", to give it the color green and the font-family of Comic Sans MS.
  • Style the span element, that is the direct child of the p element that is the direct child of div element, to give it the color red. The code should look like this:
 div > p > span{
          color: red;
 }

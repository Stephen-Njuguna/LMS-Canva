Introduction

So far, we have covered styling of both direct descendants and all descendants. However, in this lesson, we will be doing something slightly different. We will be styling only the first child of a parent element. For us to achieve this, we will use the :first-child pseudo-selector.

Instructions:

  • Create a new folder and name it pseudo_selector. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
    <h1>Meet the elements</h1>
    <div>
        <p>I am the first one. I'm obviously most significant one of all. I don't need borders to prop me together.</p>
        <p>I am the second one. They say second is the best. They're not wrong</p>
        <p>I am the third one and third times the charm</p>
    </div>
    </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • In the index.css file, insert the following code:
 div p{
    padding: 10px;
    border-bottom: 2px solid black;
   } 
  • Run the code on your browser to see the rendered page. Note that the first child of the <div> which is a <p> element has different styling from all the other <p> element.

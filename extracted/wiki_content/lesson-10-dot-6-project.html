Introduction

We have learnt a lot about selectors and now we want to put it into practice. We will style the given website using the selectors we've just learnt about.

Instructions:

  • Create a new folder and name it selector_project. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title>repl.it</title>
    </head>
    <body>
        <h1>We finished another module!</h1>
        <div class="first">
            <p>We can now style the first child of a parent element.</p>
            <p>This means we do not get the same styling</p>
            <p>BOOHOO!</p>
        </div>
        <div id="diff">
            <p>We also learnt how to style all descendants of an element</p>
            <div>
                <p>Direct or otherwise</p>
            </div>
            <p>Yay for equality!</p>
        </div>
        <p>We also learnt how to apply styling on multiple elements simultaneously.</p>
    </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • Style the first p child of the <div>, with the class name "first", and give it the color: rgb(255, 0, 0) and the font-size 24px.
  • Style all the p elements that are descendants of the <div>, with the id "diff", and give them a text-decoration of underline.
  • Style all h1 and p elements to both have the font-family, comic sans.

Introduction

The top property is used to set the top margin edge of an element and takes values in pixels. To move elements away from the top, we add more pixels and vice versa.

Instructions:

  • Create a new folder and name it top_property. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
        <div id="main">
            <h1>Top property</h1>
            <div id="relative">
                <p>When we use the top property, the element can move away or towards the top.</p>
            </div>
            <p>You can move an element down enough to block content of another element</p>
        </div>
    </body>
</html>
  • Add the following css code to the index.css file 
#relative{
  background-color: lime;
  padding: 10px;
  color: white;
  position: relative;
  /* add the styling here*/
}
  • Run the code on your browser to see the rendered page as it is.
  • In the index.css, set the top property of the div with the id "relative" and give it the value of '-20px'.
  • Refresh the page to see the rendered page and see the <div> having moved more to the top.
  • Set the top property of the div with the id "relative" and give it the value of '20px'.
  • Refresh the page see the rendered page with the div in its new position.

Introduction

The `bottom` property is used to set the bottom margin edge of an element and takes values in pixels. To move elements away from the bottom, we add more pixels and vice versa.

Instructions:

  • Create a new folder and name it bottom_property. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
        <h1>Bottom property</h1>
        <div id="relative">
            The bottom property moves elements towards or away from the bottom.
        </div>
        <p>Adding more pixels moves it further from the bottom.</p>
    </body>
</html>
  • Add the following css code to the index.css file 
#relative{
  position: relative;
  background-color: lime;
  /*add the code here*/
}
  • Run the code on your browser to see the rendered page as it is.
  • Set the `bottom` property of the div with the id "relative" and give it the value of '-20px'.
  • Refresh the page to see the rendered page and see the <div> having moved more to the top.
  • Set the `top` property of the div with the id "relative" and give it the value of '20px'.
  • Refresh the page to see the rendered page with the div in its new position.

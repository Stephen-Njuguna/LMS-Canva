Introduction

In this lesson, we are going to learn about the fixed position property. Unlike the relative property which positions itself relative to its original position, the fixed property positions elements relative to the viewport. A viewport is the screen size of the browser window on a device. When using the fixed property, the element will remain in that position on the screen even when scrolling.

Instructions:

  • Create a new folder and name it fixed_position. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
        <h1>The fixed position</h1>
        <div>
            <p>Unlike other elements</p>
        </div>
        <div>
            <p>When an element is set to have a fixed position</p>
        </div>
        <div class="fixed">
            <p>Like myself. I am somewhere on the right of the screen</p>
        </div>
    </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • In the index.css file, add the following code:
.fixed{
   position: relative;
   top: 30px;
   right: 25px;
   border: 3px solid blue;
}

  • Change the value of the position property of the ".fixed" selector to have the value 'fixed '.

  • Change the value of the top property of the ".fixed" selector to have the value '10px'.

  • Change the value of the right property of the ".fixed" selector to have the value 0. The final code should look like this:

.fixed{
   position: fixed;
   top: 10px;
   right: 0;
   border: 3px solid blue;
}

  • Refresh the page to see the rendered page.

  • Scroll up and down. You will notice that the <div> does not move from its position.

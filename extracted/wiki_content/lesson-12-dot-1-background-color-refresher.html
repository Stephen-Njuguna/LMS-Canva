Introduction:

When we learnt about colors in Lesson 3, we came across a CSS property called background-color. We use this property to give the backgrounds of our HTML elements a specified color. This lesson is intended to refresh our memories about this CSS property.

Instructions:

  • Create a new folder and name it background-color. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
        <h1>Background color refresher</h1>
        <!--Insert your code below this comment-->
    </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • Create a div with the id "desc".
  • Inside the div with the id "desc", add a p element and inside of the p element, write about your favourite sport.
  • In the index.css file, style the div with the id "desc" and give it a height of 300px, use the id selector.
  • Give the div with the id "desc" a background-color of lime and a border of 3px that is solid black.
  • Give the div with the id "desc" a padding of 10px

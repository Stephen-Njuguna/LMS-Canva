Introduction:

By default, the CSS property background-repeat has the value repeat. This makes the background image repeat itself both horizontally and vertically. If we only want the background image to repeat itself vertically, we use the repeat-y value and if we only want the background image to repeat itself horizontally, we use the repeat-x value.

Instructions:

  • Create a new folder and name it background-repeat_part2. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>

    </body>
</html>
  • Insert a div with the class name "repeat".
  • In the index.css, style the div with the class name "repeat" to have the following:
    • height set to 400px

    • width set to 300px

  • Give the div with the class name "repeat" a background-image with this URL, https://goo.gl/FNFKGP.

  • Refresh the page to see the rendered page with the div having a background image that repeats itself.

  • Give the div with the class name "repeat" a background-repeat set to repeat-y.

  • Refresh the page to see the rendered page. Notice that the background image only repeats itself vertically (up and down).

  • Change the value of the background-repeat of the div with the class name "repeat" to repeat-x.

Introduction

When adding(embedding) audio into HTML, we used the special attribute controls to give our audio default controls. There are two other special attributes we can use when embedding audio: autoplay and loop. When we want our audio to play automatically once our page has loaded, we use the autoplay attribute, which is added to the <audio> tag. The HTML will look like this:

  <audio controls autoplay>
     <source src="[https://www.elated.com/res/File/articles/authoring/html/html5-audio/WhiteChristmas.mp3](https://www.elated.com/res/File/articles/authoring/html/html5-audio/WhiteChristmas.mp3)" type="audio/mp3">
     Your browser does not support the audio element
  </audio>

When we want our audio to play on repeat infinitely, we use the loop attribute, which is added to the <audio> tag. The HTML will look like this:

  <audio controls loop>
    <source src="[https://www.elated.com/res/File/articles/authoring/html/html5-audio/WhiteChristmas.mp3](https://www.elated.com/res/File/articles/authoring/html/html5-audio/WhiteChristmas.mp3)" type="audio/mp3">
     Your browser does not support the audio element
  </audio>

Instructions:

  • Create a new folder and name it html_audio_pt_3. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <title></title>
    </head>
    <body>
        
    </body>
</html>
  • Add an <audio> tag into the body of the index.html file.
  • Give the <audio> tag the controls attribute.
  • Give the <audio> tag the autoplay attribute.
  • Add a <source> tag inside the <audio> tag.
    • Give the src attribute the following value 'https://www.elated.com/res/File/articles/authoring/html/html5-audio/WhiteChristmas.mp3'.

    • Give the type attribute the value audio/mp3.

  • Add the following text as the fallback message: "Your browser does not support the audio element".

  • Refresh the page to see the rendered page with a white bar that has a play button. The audio will automatically start playing once it has finished being loaded.

  • Remove the autoplay attribute from the <audio> tag.

  • Give the <audio> tag the loop attribute.

  • Refresh the page to see the rendered page.

  • Click the play button on the white bar. You will hear the audio play continuously.

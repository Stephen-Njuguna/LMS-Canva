Introduction

The special attributes loop and autoplay are also available for the <video> element. The loop attribute will make the video play continuously forever. The autoplay attribute will make the video play automatically when it has finished loading in the browser.Both attributes are added to the <video> tag.

Instructions:

  • Create a new folder and name it html_video_pt_2. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <title></title>
    </head>
    <body>

    </body>
</html>
  • Add a <video> tag into the body of the index.html file.
  • Give the <video> tag the controls attribute.
  • Give the <video> tag the loop attribute.
  • Give the <video> tag the width attribute with the value 320.
  • Give the <video> tag the height attribute with the value 280.
  • Add a <source> tag inside the <video> tag
    • Give the src attribute the following value 'http://henriksjokvist.net/examples/html5-video/video.m4v'.
    • Give the type attribute the value video/m4v.
  • Refresh the page to see the rendered page with a video embedded in it. Click the play button. The video will play continuously.
  • Remove the loop attribute.
  • Give the <video> tag the autoplay attribute.
  • Refresh the page to see the rendered page. The video will now start playing automatically once it has finished loading.

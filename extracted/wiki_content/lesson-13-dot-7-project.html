Introduction

We have learnt how to embed both audio and video in our HTML documents and now it's time to put this into practice.

Instructions:

  • Create a new folder and name it html_video_project. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <title></title>
    </head>
    <body>

    </body>
</html>
  • Add a <video> tag into the index.html.
  • Give the <video> tag the controls attribute.
  • Give the <video> tag the loop attribute.
  • Give the <video> tag the width attribute with the value 300.
  • Give the <video> tag the height attribute with the value 240.
  • Add a <source> tag inside the <video> tag.
    • Give the src attribute the following value 'https://www.html5rocks.com/en/tutorials/video/basics/devstories.webm'.
    • Give the type attribute the value video/webm.
  • Add an <audio> tag into the body of the index.html file.
  • Give the <audio> tag the controls attribute.
  • Give the <audio> tag the autoplay attribute.
  • Add a <source> tag inside the <audio> tag.
    • Give the src attribute the following value 'https://www.elated.com/res/File/articles/authoring/html/html5-audio/WhiteChristmas.mp3'.
    • Give the type attribute the value audio/mp3.
  • Run the code on your browser to see the rendered page with the video and the audio that plays automatically after the page has finished rendering.

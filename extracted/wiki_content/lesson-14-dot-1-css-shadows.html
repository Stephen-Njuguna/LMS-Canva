Introduction

In CSS, we can add shadows to our elements. This is possible using two CSS properties:

  • text-shadow
  • box-shadow

We can only add shadows to elements (except the body element) and the text inside of them.

Instructions:

  • Create a new folder and name it css_shadows. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <title></title>
    </head>
    <body>
        <div>
            <p>Casper The Friendly Ghost</p>
        </div>
    </body>
</html>
  • Add the following css code to the index.css file 
body{
  background-color: black;
}

div{
  background-color: white;
  display: flex;
  justify-content: center;
}
  • Run the code on your browser to see the rendered page as it.
  • Link the index.css file to the index.html.
  • Add the following styling into your index.css file:
.shadow{
   padding: 10px;
   font-size: 24px;
   text-shadow: 2px 2px 5px blue;
}

  • Give the p element a class name "shadow".

  • Refresh the page to see the rendered page with the content inside the p element having a shadow.

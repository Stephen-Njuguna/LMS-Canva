Introduction:

In this project, we are going to recreate a website. The website is going to look like a page on YouTube while watching a video. This project is intended to help you practise embedding HTML media but will not resemble a YouTube page.The website will look like this:

  

Instructions:

  • Create a new folder and name it Project 3. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
        <div class="header">
            <p id="home">MeTube</p>
            <p id="username">Senior SPOC </p>
        </div>
        <div>
                
        </div>
    </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • Give the second div a class name "main".
  • Insert a <video> element into the div with the class name "main".
  • Give the <video> tag a controls attribute.
  • Give the <video> tag a height attribute with the value of 400.
  • Give the <video> tag a width attribute with the value of 720.
  • Insert a <source> tag inside the <video> element.
    • Give the src attribute the following value 'https://www.tutorialrepublic.com/examples/video/shuttle.mp4'.
    • Give the type attribute the value video/mp4.

    • Add the following text as the fallback message: "Your browser does not support the video element"

  • Add a <p> tag after the <video> element and give it an id "description".

  • In between the <p> tag with the id "description", insert the following words, "Space Shuttle Launch".

  • Refresh the page to see the rendered page with the video embedded into it. Now let us style it.

  • Give the body element the following styling:

    • Set the margin to have a value of 0
    • Set the width to have a value of 100%
  • Give the div with the class name "header" to have the following styling:
    • Set the width to 100%
    • Set the height to 50px
    • Set the box-sizing to border-box
    • Set the background-color to red
    • Set the box-shadow to 0px 5px 5px grey
    • Set the position to fixed
    • Set top to 0
    • Set the display to flex
    • Set the justify-content to space-between
  • Using the combining selector (,); style both the <p> elements with the id "home" and the id "username" to have the following styling:
    • Set the color to white
    • Set the font-family to sans-serif
  • Give the p with the id "home" the following styling:
    • Set the margin-left to 30px
  • Give the p with the id "username" the following styling:
    • Set the margin-right to 30px
  • Give the div with the class name "main" to have the following styling:
    • Set the width to 100%
    • Set the height to 500px
    • Set the margin-top to 50px
    • Set the box-shadow to 0px 5px 5px grey
    • Set the display to flex
    • Set the flex-direction to column
    • Set the align-items to center
    • Set the justify-content to center
  • Give the p element with the id "description" the following styling:
    • Set the font-size to 24px
    • Set the font-family to sans-serif
  • Refresh the page to see the rendered page. It will look like the example in the picture above.

We will break the project into smaller sections just to familiarize ourselves with the concepts needed to build this project. The first step in this lesson is the background image.

Instructions:

  • Create a new folder and name it Tembea Africa. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width">
    <title></title>
    
  </head>
  <body>
    <!--Write your code in here-->
  </body>
</html>
  • Run the code on your browser to see the rendered page as it is.
  • Link the CSS file to the HTML file as always.
  • Create a div with the class name container in the html file.
  • Within the div container, create a new div this time giving it an id overlay.
  • In the index.css file we will style the .container in order to achieve the desired background as follows:
.container {
   position: absolute;
   top: 0;
   bottom: 0;
   right: 0;
   left: 0; 
   background-image: url(https://i.imgur.com/m2GPoD5.jpg);
   background-repeat: no-repeat;
   background-size: cover;
} 

  • Refresh the page to see the rendered page.

  • Next, we will be making the image appear a little darker by adding an overlay to it.

  • To achieve this, we will style our div given the id overlay, as follows:

#overlay{
   position: fixed;
   overflow: auto;
   width: 100%;
   height: 100%;
   top: 0;
   left: 0;
   right: 0;
   bottom: 0;
   background-color: rgba(0, 0, 0, 0.5);
   z-index: 2;
}

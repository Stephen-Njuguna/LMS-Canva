In this lesson, we will learn about navigation. This is basically the bar at the top of a website that contains a couple of links to information regarding a particular website.

Notice that the red arrow points towards the navigation bar.

Example of code written to create a navigation bar looks like this:

<nav>
<ul>
<li><a href="#home">Home</a></li>
<li><a href="#sports">Sports</a></li>
<li><a href = "#academics">Academics</a></li>
<li><a href="#about">About</a></li>
</ul>
</nav>

In creating the navigation bar, it is good to note that there is a nav tag introduced.

The items in a list are to be links hence the use of the <a></a> within the li tags

The reference points towards the particular div containing the required information if it is within the same page.

Introduction

Today we will use our knowledge of HTML and CSS to impact our community in a positive way. Think about the values and amazing aspects that your school has and how you can make a small outline and design of how you can make a great website out of that.

So let’s get right to it.

Instructions:

  • Create the necessary folder and files. i.e the project folder and inside it the html and css files
  • Source for images online that would best resonate with your school.
  • Link the CSS file to the HTML file as always.
  • Create a div with the class name **container** in the html file.
  • Within the div with the overlay id, add in a nav bar with the following links:
    • Welcome
    • Scholar Life
    • Clubs & Activities

    • Contacts

  • Create a new div after the nav bar with the id slogan.
  • Create a slogan for your school within a h2 tag in that div.
  • Create a new div with the id scholar and add a h3 tag with the title Scholar life
  • Add an image link of students in your school.
  • Create three paragraphs describing the day to day student experience in your school
  • Create a div with the id activities and add a h2 with the title Clubs & Activities
  • Within the activities div create new divs with the following ids:

    • music

    • writing

    • dance

    • And add a h3 tag with their respective titles, i.e Music, Writing and Dance. Add a paragraph for each, explaining what these clubs are about and how they are run in your school

  • Create a new div beneath the Clubs & Activities div with an id classes.

  • Within the classes div add a h3 with the title Future Students that will be followed by a paragraph with a brief description on the steps that your school takes when recruiting new students.
  • Add another h3 with the title Current Students followed by a paragraph explaining the qualities and skills of the students currently in your school.
  • Finally, add a h3 with the title Alumni students followed by a paragraph describing what fields and careers students who finish studying in your school venture into.

  • Create a div with the id contacts. Here, you can add information about your school.

  • Now let's style up our website.

  • Styling the .container:
    • Set the position to relative
    • Set top, bottom, right and left to 0
    • Set the background-image to a school image of your choice. (you may also use this http://bit.ly/2FTO7VA)
    • Set background-repeat to no-repeat
    • Set the background-size to cover
  • Styling the body:
    • Set font-size to 1.3em
    • Set font-family to 'Work Sans', sans-serif
  • Styling the nav:
    • Set the margin to 0 auto;
    • Set the padding to 0.1% 0;
    • Set the margin-right to 0;
  • Styling the nav>ul:
    • Set text-align to right
  • Styling the ul>li :
    • Set the display to inline-block
  • Styling the ul>li>a:
    • Set the text-transformation to uppercase
    • Set the padding to suitable proportion in %.
    • Set text-decoration to none
    • Set color to rgba(255, 255, 255, 0.733);
  • Styling the ul>li>a:hover:
    • Set box-shadow to 0 0 0 0.625em rgba(0, 0, 0 , 0.1), insert 0 0 0.625em rgba(255, 255, 255, 0.6)
    • Set background-color to rgba(107, 93, 84, 0.678)

    • Set color to rgba(0, 35, 122, 0.7)

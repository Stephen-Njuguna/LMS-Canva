Introduction:


We will learn how to embed images into our HTML pages in this section.

We can embed images into HTML pages by using the <img> tag. 

Instructions:

  • Create a new folder called html_images and inside that folder create a file called index.html.
  • Add the following code in the index.html file
<!DOCTYPE html>
<html>
  <head>
    <title>HTML Images</title>
  </head>
  <body>
    <h1>How to embed an image into an HTML page.</h1>
    <p>We embed images into HTML pages to make them look nice. Additionally, they can convey a lot more than just text - remember the saying that "An image is worth a thousand words?"</p>
    <img>
  </body>
</html>

Please take note of the <img> tag after the <p> </p> tag.

When we run this html code on the browser, you'll notice that no image shows up yet even though we have included an <img> tag in our html.  This is because we have not yet specified the source of the image. We will do that in the following lesson.

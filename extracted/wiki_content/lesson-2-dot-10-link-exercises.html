Let us create some more links.
We've carried over code from the last section.

Instructions:

  1. Create an ordered list (ol) with 2 li items.
  2. Each of the item will be a link to a page on the Moringa School website.
  3. Put an a element in between the opening and closing li tags of each of the item elements.
  4. Each li element will now look like this: <li><a></a></li>
  5. Between the first set of a tags, type "Moringa School main website", and for the second, "Moringa School website blog".
  6. Add href attributes to both a elements with values http://www.moringaschool.com and http://www.moringaschool.wordpress.com respectively.
  7. Add target attributes to each link, the first with a target of _blank and the second with _self.

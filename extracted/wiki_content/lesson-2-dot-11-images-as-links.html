We can also use images as links. Let's see how we can achieve this

For the purpose of this lesson, we'll use the code we wrote when learning about html images. This code should be inside the file called html_images.html. As a recap the code looks like this:

<!DOCTYPE html>
<html>
  <head>
      <title>HTML Images</title>
  </head>
  <body>
      <h1>How to embed an image into an HTML page.</h1>
      <p>We embed images into HTML pages to make them look nice. Additionally, they can convey a lot more than just text - remember the saying that "An image is worth a thousand words?"</p>
      <img class="image" src="https://bit.ly/3ccpBCv" height="200" >
      <img  height="200" alt="Transformers Image" >
  </body>
</html>

We'll make the second image point to a webpage that has more information about transformers, and make it open in a different tab/window using the target attribute. 

We do this by wrapping the img tag of an image in an a element, like this:


<a href="#"><img height="43" src="url"></a>

Instructions:

  • Wrap the second image element in an <a></a> tag.
  • Add the src for the second image to be "https://bit.ly/36y7xzf". 
  • Then add a href attribute to the <a> tag with value of "https://en.wikipedia.org/wiki/Optimus_Prime". 
  • Finally, add a target attribute with a value of  "_blank"
  • This part of your code should look similar to this:
      <a href="https://en.wikipedia.org/wiki/Optimus_Prime" target="_blank">
          <img src="https://bit.ly/36y7xzf" height="150">
      </a>
  • When we run it on the browser, the second image is now a link. When clicked, the page at the specified link will load in a new tab.

Your code for the whole page should look like this:

<!DOCTYPE html>
<html>
  <head>
    <title>HTML Images as links</title>
  </head>
  <body>
      <h1>Embedding an image into an HTML page and making it a link</h1>
      <p>We embed images into HTML pages to make them look nice. Additionally, they can convey a lot more than just text - remember the saying that "An image is worth a thousand words?"</p>
      
      <img class="image" src="https://bit.ly/3ccpBCv" height="200" >
      
      <a href="https://en.wikipedia.org/wiki/Optimus_Prime" target="_blank">
          <img src="https://bit.ly/36y7xzf" height="200">
      </a>
  </body>
</html>

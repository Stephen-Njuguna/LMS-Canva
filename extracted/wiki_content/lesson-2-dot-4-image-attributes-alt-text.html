The alt attribute defines an alternative text for an image.

This text is displayed in place of the image specified in the src attribute cannot be displayed.

Instructions:

  • Modify the code you have now to look like the following
<!DOCTYPE html>
<html>
  <head>
      <title>HTML Images</title>
  </head>
  <body>
      <h1>How to embed an image into an HTML page.</h1>
      <p>We embed images into HTML pages to make them look nice. Additionally, they can convey a lot more than just text - remember the saying that "An image is worth a thousand words?"</p>
      <img class="image" src="https://bit.ly/3ccpBCv" height="200" >
      <img  height="200">
  </body>
</html>
  • Now run the modified code on the browser. Notice that the second image isn't displayed. That's because it doesn't have a valid src.
  • Add an alt attribute to the second image with a value of "Spotted Transformer." You should have something like this for the image code:
<img height="150" alt="Spotted Transformer">
  • Run the code again. This time the second image will show a text instead of an image.

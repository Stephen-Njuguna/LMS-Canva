We now know a lot about embedding images.

Let us make a catalogue of some popular Supermarkets in Kenya. Below are URLs for images of supermarket logos.

  • https://bit.ly/3prYKX0 - Nakumatt Supermarket.
  • https://bit.ly/39o7lEn- Tuskys Supermarket

Instructions:

  • We have created a new html code (as shown below) that has short paragraphs for each of the super-markets. After each paragraph, add an img tag. 
<!DOCTYPE html>
<html>
  <head>
      <title>Introduction to HTML</title>
  </head>
  <body>
      <h1>A few popular Super Markets in Kenya</h1>
      <h3>Nakumatt Super Market </h3>
      <p>Nakumatt was originally called Nakuru Mattresses Supermarket</p>
  
      <h3>Tuskys Supermarket</h3>
      <p>The original name of this supermarket was Tusker Mattresses Supermarket</p>
  
  </body>
</html>
  • For each img tag, add an src attribute with the respective url values from the list above. You can copy and paste the urls.
  • For each img tag, add a width attribute with value "200".
  • Run the code on the browser to see the results

A data type is a classification of data (a collection of information),

The first data type we are going to explore is the string.

String

A string is any grouping of keyboard characters surrounded by single quotes 'watch!' or double quotes "watch!" They simply represent text..

console.log("I am a string look at me!");
console.log("!&#$");
console.log("764");

What's between the quotes is what we call a string.

Strings can include letters, punctuation and even numbers!

Booleans are values that can be either true or false.

This is how Boolean values look like

var rainy = true;
var funny = false;

Let's put it into practice

For example, a Boolean value about you would be whether you wear glasses.

If you wear glasses, it's true , if you don't it's false

glasses = true;
iLikeBroccoli = true;

We will practice more of Boolean data types very soon

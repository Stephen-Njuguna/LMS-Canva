Introduction

So far we've been writing all our javascript code on the console. As powerful as the console is, it also has it's limitations. 

You may have noticed that it is difficult to write multiple lines of code without running/executing the code. This is one of its limitations. 

Furthermore, as programmers, we will not be writing our javascript code on the console directly.  We'll be writing our javascript code in a javascript file then execute it on the browser just like we did with Html files. 

Just like Html files, all javascript files must have a .js extension i.e when we are creating a javascript file we must include the .js extension after we name the file, for example, hello_world.js. This helps the code editors and browser to recognise javascript files.

Let's try it out.

Navigate to your documents folder, inside it create a folder and name it javascript. This is where you'll put all the javascript files we'll create in the upcoming lessons. 

Let's create our first javascript file. So, create a file called hello_world.js. Open in using VS code editor.

Add the following code:

console.log("hello world")

Now comes the million-dollar question, how do we execute it? 

Luckily since we are using Visual studio code (VS Code) as our code editor, it allows us to install a tool that will help us execute our javascript code directly from our editor. It has a feature called extensions that let us add languages, debuggers, and tools to our installation to support our programming workflow. 

We are going to install a VS Code extension called code runner that will execute our javascript code.

Follow the following steps:

  • On the left side panel in vs code, click the extensions icon

  • An extension panel will appear, type in "code runner' in the extension panels search box.  You should see it appear as the first result.

  

  • Click 'Install' to install the extension.  Close the Extension: Code runner tab.
  • Now, you should see a    icon appear on the right top corner of the vscode window. We are going to be using this icon to run our javascript code. 

 

Let's now run our code. Click on the icon to run the code.

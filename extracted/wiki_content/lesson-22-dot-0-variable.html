Variables are like containers in JavaScript, you can put any value in them. They can store information that can later be used in calculations and displays.

For this lesson, create a javascript file called variables.js

To create a variable in Javascript, we need to use the keyword var it must be in small letters.,

Below is an example of how we create/declare a variable:

var person;

console.log(person);

Click run ( ) to see what the console displays, it displays undefined This is because we haven't assigned a value to the variable person Let's get to it.. .

Below is how we give the variable a value, in this cause the value of the variable person will be a string:

var person;

person = "Christine"; //The string has been stored

console.log(person);  //displays the value of person

Notice that we use the = sign to assign data to the variable named person .

The string has now been saved into the variable person.

Click run ( )  to see what the console displays.

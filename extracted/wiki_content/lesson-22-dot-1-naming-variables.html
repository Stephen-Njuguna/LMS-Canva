Naming variables is very important. You should name the variables in relation to what you are trying to create. For example you may want to build a car, you will have parts like wheel, mirror, lights and so on, When creating these variables you can use the names of these everyday items to name them.  

eg var wheel, var lights, var mirror

You have to take extra precaution because it's easy to misspell them or capitalize them wrong the console won't know what you are talking about.

Rules of Naming Variables!

  1. MUST start with a lowercase letter

For example:

food (Correct)Food (Wrong)

  1. MUST not contain spaces, for example:

food (Correct) Fo od (Wrong)

There are some names we cannot use when naming variables. these are called reserved words.

The list of reserved words includes break, else, false, private, and protected

Click this link to access the list of all reserved words: https://www.w3schools.com/js/js_reserved.asp

The reason we are restricted from using these words is that they have special meaning in JavaScript.

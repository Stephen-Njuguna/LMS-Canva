Sometimes you may want to change the strings from lowercase to uppercase or to capitalize the first word of a sentence and vice versa.

var crazyCase = "mY nAmE is caPtAIN AMErica";
console.log(crazyCase.toLowerCase); //logs on the console

The variable crazyCase is unreadable, but we can change it to different cases.

Instructions

  • Create a javascript file  and name it upper_case_and_lowe_case.js
  • Create a variable named crazyCase and assign it the string "mY nAmE is caPtAIN AMErica".

  • Use the following methods to change the case of the string.

    crazyCase.toLowerCase();

    crazyCase.toUpperCase();

  • Console log both the cases separately.

  • Click run and observe the results in the console

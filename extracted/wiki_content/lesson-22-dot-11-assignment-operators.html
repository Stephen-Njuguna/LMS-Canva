Introduction:

So far we have learnt a couple of new concepts that we also reviewed in the previous lesson.

We now know that the = sign is used to assign a value to a variable. Hence it is called an assignment operator.  In the example below, number is assigned the value 35.

Another assignment operator is the += operator, because it too assigns a new value to a variable.

We have learnt how to add and subtract numbers.

Simply done,

var age = 5;

age = age + 2; //changing the value of the variable

console.log(age); //prints out 7

JavaScript gives us a simpler way to do this.

Here is an example of how that happens:

var age = 5;   // declaring age as  5

age += 2;  increasing the value of age by 2

console.log(age); // prints out 7

There is an assignment operator for each Math operator we have learnt about that is. Addition, subtraction, multiplication and even division.

+=

-=

*=

/=

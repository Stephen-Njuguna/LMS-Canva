Introduction:

We have learnt about the Math operators and the assignment operators.

Next up we have the comparison operators. They do not change any values. They compare two values, and return true or false (Boolean) depending on whether the statements are true or false.

var newNumber = 10;  // declaring a new variable newNumber and assigning it a value of 10.

  

newNumber === 9;   // a statement checking if newNumber is equal to 9.

Notice the 3 = signs in the example above.

This === asks whether something is equal.

In this case, we are asking whether newNumber is equal to 9.

That is not true hence when we console.log newNumber === 9  what appears on the console is the word false.

That is because we see that the value of newNumber is 10.

NOTE:

In comparison operators we have both == and === They both compare values, however, == compares , loose equality while === compares strict equality.

In loose equality, for example

console.log(77 == '77'); //the console should return a true value.

Although the console returns a true value, we know that 77 and '77' are not completely the same as they both have different data types, one being a number data type and the other being a string data type

In strict equality, for example

console.log(77 === '77'); //the console should return a false value

Here, everything should be the same, from the value to the data type and the number of characters.

Comparison operators work for strings as well:

var animal = "giraffe";

console.log(animal);

  

animal === "elephant";

console.log(animal === "elephant);

//false is printed out because animal is equal to giraffe and not elephant.

Other comparison operators include:

Other comparison operators include:

< this operator means less than but not equal to.

> this operator means greater than but not equal to.

<= this operator means less than and equal to.

>= this operator means greater than and equal to.

!== this one looks new to us, it means not equal to.

We will practice more on these operators in a few lessons.

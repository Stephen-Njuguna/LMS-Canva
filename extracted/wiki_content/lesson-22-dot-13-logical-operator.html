There are three main Boolean operators in JavaScript, &&, || and !. They look a bit too complex but with a bit more practice they are easy to understand, and they will come in handy.

&& (AND)

&& means and, we use these operators with Boolean values to see if they are both true.

For example if you want to make a burger you have to make sure you have a bun and a patty. If you have both then you can make the burger. Got it?

Okay let's put it into practice. Create a javascript file  and name it Logical_operator.js

Now, let's create Boolean operators and see if we can make our burger

var bun = true;

var patty = true;

bun && patty; 

//_the console should print out 'true' because both the bun_ 
_//and patty are true then bun && patty are also true_

So what happens when we don't have any of the ingredients? We can't make the burger, let's try it out.

var bun = true;

var patty = false; 

bun && patty; //the console should print out 'false'

If both values are true, then the whole statement is true. If either value, or both values, are false, then the whole statement is false.

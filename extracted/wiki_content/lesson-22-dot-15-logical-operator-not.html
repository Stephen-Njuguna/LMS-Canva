Introduction

Not is a Boolean operator that is represented by this symbol: ! .

It is used to turn false values to true and vice versa,

var veggiesAreGood = true;

var yuck = !veggiesAreGood; //

console.log(yuck);

We set the variable veggiesAreGood to true but some of us don't like veggies so we created another variable yuck and we turned the value of veggiesAreGood to false. ,

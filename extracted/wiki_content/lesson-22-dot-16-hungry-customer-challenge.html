Combining Logical Operators

We can work with all the logical operators together.

For this lesson, create a javascript file  and name it hungry_customer_challenge.js

Say you run a burger shop and you have hungry customers making orders for a burger and you have all the following ingredients: the bun, patty, cheese and veggie.

First, we will create the four variables and set to true:

var bun = true;

var patty = true;

var cheese = True;

var veggie = true;

var mayonnaise = false; 

var ketchup = false;

Your first hungry customer orders a veggie burger with no cheese and either ketchup or mayonnaise.

Let's create another variable for the customer's order to store their order.

var order = bun && patty && veggie &&( ketchup ||mayonnaise);

var happyCustomer = order //true is for happy customer 
                          //and false is for angry customer

Just like in math, how we calculate multiplication before addition using BODMAS, JavaScript calculates && AND before || OR  therefore we put the OR operator in brackets. We can consider the AND operator as our multiplication and OR as division just to make things simpler,

In this case the burger MUST have the bun, patty, veggie and ketchup or mayonnaise.

The Ketchup or mayonnaise are options for the customer.

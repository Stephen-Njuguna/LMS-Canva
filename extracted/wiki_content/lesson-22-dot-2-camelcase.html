Introduction:

This has to do with how we name our variables. Initially, we used just one word, which had to start with a lowercase letter. We can actually use two or even three. When using more than one word in our variable names, what we need to understand is that the words are not spaced but instead written as one word, where the first letter of each word after the first is capitalized.  For example, we would write "camel case" like this: camelCase.

The reason behind it being called camel case is because the capitalized words are shaped similar to the humps of a camel.

A practical example:

var myNumber = 43; // created a variable with a name in camel case

var candyCaneIsSweet = true; 

var rainyDay = "Carry your umbrella";

Introduction:

Notice that it's called a "variable"? What this means is that, although we give the variable a certain value, we can also change that value.

Here's how:

var fruit = "Passion";  //declaring a variable named fruit and assigning it the value "Passion"

  

console.log(fruit);  // displaying the current value of the fruit variable, which is  "Passion"

  

fruit = "Orange";    //changing the value of the fruit variable from "Passion" to "Orange"

  

console.log(fruit);  //displaying the current value of the fruit variable, which is "Orange";

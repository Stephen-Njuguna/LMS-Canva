Introduction

In this lesson, we will learn about two more operators that are very useful when writing code: increment and decrement.

The increment operator increases the value of a number by 1 and is represented by  two plus signs ++ .

Example on how the increment operator works :

var timer = 5;  // assigning the variable timer a value of 5

console.log(timer);  //printing out value of timer as 5

timer ++ // increasing the value of the variable timer to 6

console.log(timer);  //displaying timer as 6

The decrement operator decreases the value of a number by 1 and is represented by two minus signs -- .

Example of how the decrement operator works:

var timer = 5;   // assigning variable timer a value of 5

console.log(timer);   // printing out timer as 5

timer --;    //  decreasing the value of the variable by 1

console.log(timer);  // printing out timer as 4

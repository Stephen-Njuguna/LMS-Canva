Recap: Strings are any keyboard characters surrounded by by quotes.

Concatenation is a very big word but it basically means "joining two or more things together".

For this lesson, create a javascript file  and name it concantenation.js

In programming, we join two or more things using the + operator.

Here's how we can join strings together:

var first = "Ice";

var second = "cream";

console.log (first+second); //this is how we concatenate strings

Type this into the editor and click run to display it on the console.

var name = "I am Stringy";

var age = 'I am 10 years old';

var home = "I live in a yarn";

console.log(name + age + home);

Note that concatenation uses the addition operator, however with strings it joins two different strings, while in numbers it performs a math operation

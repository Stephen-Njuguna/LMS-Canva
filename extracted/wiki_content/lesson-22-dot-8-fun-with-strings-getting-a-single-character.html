We are going to find or pick a single character from a string.

For this lesson, create a javascript file  and name it getting_string_character.js

In this case, we use square brackets [ ] .

Let's try and get a specific letter or character from this string

var thisString = "Awesome";
console.log(thisString[0]); //gets the first character "A"

console.log(thisString[5]); //gets the fifth character "m"

Notice that from the first character of the string, we use 0 instead of one, This is because in programming languages such as JavaScript we start counting from zero instead of one.

When you want the first character of a string you use 0 and for the second character, you use 1 and so on.

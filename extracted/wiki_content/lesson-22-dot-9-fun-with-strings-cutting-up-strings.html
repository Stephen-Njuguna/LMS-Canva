For this lesson, create a javascript file  and name it string_slicing.js

We use the method .slice() to cut up strings. For example you may want to grab words from a sentence or paragraph to display as the title of your story, we can do this using slice.

var cutThisUp = "The wheels on the bus";

console.log(cutThisUp.slice(4, 13)); //this should display wheels on

The numbers in the parenthesis specify the first character you want to display to the last one, this means you may have to count your characters to know from where to where you need to slice. This also includes spaces.

You only use the position of the first character for the word you want to display and the position of the first character of the last word that you want to display.

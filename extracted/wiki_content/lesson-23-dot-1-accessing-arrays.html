Remember when we used square brackets to access specific characters in a string?

That's exactly how arrays work too.

var bucketList = ["Morocco", "Cuba", "Kenya", "Tanzania", 
"South Africa", "Ethiopia"];

Remember we count our items starting from 0? Well, it's the exact same way with arrays.

Say we want to access the 3rd item on our list, we will use console.log(bucketList[3]); to display the item on the console.

For this lesson, create a javascript file and name it accessing_arrays.js

Instructions

  1. Using square brackets, log "Cuba" to the console. Then log "South Africa" and "Ethiopia".
  2. Click run to display the items.

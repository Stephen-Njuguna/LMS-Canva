Let's say you don't want to go to Kenya anymore, but instead want to go to Zanzibar. Let's see how we can change Kenya to Zanzibar in the array.

`var bucketList = ["Morocco", "Cuba", "Kenya", "Tanzania", "South Africa", "Ethiopia'];` 
`bucketList[2] = "Zanzibar";`

The array should look like this:

["Morocco", "Cuba", "Zanzibar", "Tanzania", "South Africa", "Ethiopia'];

Yay, now you can go on vacation to Zanzibar,

We can also add another item onto our list by using the method .push().

bucketList.push = "Canada"; //adds to the end of the list

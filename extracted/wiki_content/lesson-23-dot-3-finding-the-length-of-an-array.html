Properties and Methods help us work with arrays. Properties tell you something about the array while methods do something to change the array.

We have already learned that strings have properties and methods. Just because this is so important, we're going to learn how to use them with arrays as well.

Similar to how we got the length of a string, we use the .length method.  

var bucketList=["Morocco", "Cuba", "Zanzibar", "Tanzania", "South Africa", "Ethiopia"];

We are going to cover more of the .push() method we already introduced in the beginning of this lesson.

Create a javascript file  and name it push_array_method.js

Say we are going for our trip and we want to make a packing list.

Let's create an empty array and call it packingList .

`var packingList = [];`

Now let's get packing .

We can add elements into our array by using the .push() method.

We'll probably need binoculars, a journal, a camera, and a tourist hat.

Let's add the first item on our list into our array.

packingList.push("binoculars");
console.log(packingList);

The code has been typed for you in the editor.

Click run to see that binoculars has been added to your list.

Now let's add the rest of our list.

packingList.push("journal");
packingList.push("camera");
packingList.push("touristy hat");
console.log(packingList); // ["binoculars", "journal", "camera", "touristy hat"]

To add an item to the top of our list we can use .unshift() method.

Here's how it would look like.

packingList.unshift("sunglasses");

You can also use the .concat() to join more than one array.

Say we have more than two lists we want to join. Let's see how that is done.

var birds = ["Parrots", "Owls", "Penguin"];
var reptiles = ["Lizards", "Turtles","Dinosaur" ];

var amphibians = ["Frogs", "Salamanda","Caudata" ];

var mammals = ["Humans", "Elephants","Sloths" ];

To join all these lists together we use commas to separate the lists we want to join.

For example, if we have an array named animals and we want to join it with other arrays for specific types of animals. We can join different kinds of animals like this. ,

animals.concat(amphibians, reptiles, birds, mammals);

An object is a collection of related information. Just like arrays they have properties and methods.

Objects make coding simpler and non-repetitive.

From our previous lesson we learnt that properties tell us more about an item while methods make change it or make it do something.

An object looks like this:

var newObject = {
key : value,
key2 : value2,
key3 : value3
};

Where newObject is the new object, key is the name of the property and value is the attribute of the property.

An attribute tells us more about something, basically also called characteristics.

When we combine the keys and their values, we have the key-value pairs.

Creating an object often begins with creating a variable:

var person = {}; //notice that we used curly brackets instead of square brackets

We have just created an empty object but there is not much we can do with it.

Let's add some properties to it and values to the properties.

var person = {
	name : "Wambui Kinyua",
	age : 16,
	gender : "female"
	}

Notice that we use commas to separate the properties. However, we don't use one for the last property because it's the last on that list.

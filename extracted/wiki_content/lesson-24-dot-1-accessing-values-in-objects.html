We were able to access values in arrays using the index. In objects, we access the values using the keys.

Remember in arrays when we used methods like .push() to add items to packingList? The. here is called dot notation It helps use get things from our lists.

We will use the dot notation to get values from our objects using the keys.

Let's get properties from our object person.

var person = {
	name : "Wambui Kinyua",
	age : 16,
	gender : "Female",
	hobbies : ["Dancing", "Reading", "Nature trails", "Cooking"],
	}

If we want to get the name of the person in this case we will console log person.name :

console.log(person.name); // "Wambui Kinyua" prints to the console

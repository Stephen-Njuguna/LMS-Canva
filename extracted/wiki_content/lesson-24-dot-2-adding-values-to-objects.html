We can add values to an object using the dot notation.

var person = {
	name : "Wambui Kinyua",
	age : 16,
	gender : "Female",
	hobbies : ["Dancing", "Reading", "Nature trails", "Cooking"]

}

Here's how we add new key value pairs to an object, let's add a Boolean property about Wambui:

person.isAwesome = true;

We have added a key property isAwesome and we have assigned it a key value true .

Instructions

  1. Type person.isAwesome in the editor and assign it true
  2. Console log person .
  3. Click run and observe the results in the console

We use the delete keyword to remove property keys and their values from an object.

var person = {
	name : "Wambui Kinyua",
	age : 16,
	gender : "Female",
	hobbies : ["Dancing", "Reading", "Nature trails", "Cooking"],
	isAwesome : true,
	favoriteColor : "Yellow",
	eyeColor : "brown"
};
We can remove Wambui's `eyeColor` like this:

delete person.eyeColor;

Instructions

Type the code above in the editor, use delete to remove Wambui's eyeColor from the object.

  1. Console log person to view the object, `console.log(person);`
  2. Remove Wambui's hobbies from the object.
  3. Click run and view the results in the console

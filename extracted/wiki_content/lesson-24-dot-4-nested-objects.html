A nested object is an object inside an object.

Just like objects can have an array as a property, they can also have other objects as properties.

var person = {
	name : "Wambui Kinyua",
	age : 16,
	gender : "Female",
	hobbies : ["Dancing", "Reading", "Nature trails", "Cooking"],
	isAwesome : true,
	sibling: { //this is the nested object
                  name : "Mwangi Kinyua",
                  age :  13,
                 }
};

We can also access the nested object in this case. Here's how:

console.log(person.sibling.name); // "Mwangi Kinyua"

Instructions

  1. Type the object above into the editor.
  2. Console log the age of the sibling.
  3. Click run and observe the results in the console.

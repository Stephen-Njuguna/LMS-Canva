We have already seen how we can add arrays to an object, now let us get a little bit more advanced with it.

We can start by creating an array of Wambui's friends. In the array, Wambui's friends are all objects. Remember how we separated each item in an array with commas, we will do the same here. Each object is an item in the array, however, the object holds information about each friend.

var friends = [{
 name: "Kiro",
 age: 15
    },
    {
 name: "Patty",
 age: 17
    },
    {
 name: "Sandy",
 age: 14
    }
];

To get information about Wambui's second friend, we can use the same technique we used in arrays.

console.log(friends[1]); // Wambui's second friend is index 1

Remember we start counting from 0.

If we only want to get the name of Wambui's second friend, we can log the array index and use the dot notation after to get the name.

console.log(friends[1].name); // "Kiro"

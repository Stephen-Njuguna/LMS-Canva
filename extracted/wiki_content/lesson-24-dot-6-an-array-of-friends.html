Let's have a little challenge right here.

We will create an array of friend objects, where each object also contains arrays. Sounds tricky huh? We can totally hack this.

Let's start by creating three objects that have arrays in them. Each object has three properties, that is, name age and favoriteAnimals Each favoriteAnimals property is an array. . ,

var kiro = {
 name: "Kiro",
 age: 15,
 favoriteAnimals: ["Duck", "Monkey", "Whale"]
};
var patty = {
 name: "Patty",
 age: "17",
 favoriteAnimals: ["Snake", "Lion", "Zebra"]
};
var sandy = {
 name: "Sandy",
 age: "16",
 favoriteAnimals: ["Flamingo", "Chicken", "Gecko"]
};

Next we will create an array of Wambui's friends to hold the objects we just created.

var friends = [kiro, patty, sandy]; //array to hold our objects.

We can now try to access any information about Wambui's friends. For example if we want to get Sandy's information from our array, this is how we'd do it.

In our previous lessons, we learnt how to access arrays, using indices (the position of the array). In the same exact way we can access Sandy's information.

console.log(friends[2]);

Now let's get specific information about Sandy, say, her 2nd favorite animal.

console.log(friends[2].favoriteAnimals[1]); 
/*console should display chicken
her second favorite animal is index 1 since we start counting arrays from 0,

The key favoriteAnimals is an array too. We will use the dot notation to access the favoriteAnimals key in the object and include its index since we need to know what that animal is.

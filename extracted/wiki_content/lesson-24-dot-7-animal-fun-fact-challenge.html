There are so many animals in Africa. We would like tourists to know more about the animals we have in Africa. It would be great if we can store this information collectively so it's easy to access it.

We will combine arrays, objects and nested objects.

For this lesson, create a javascript file and name it challenge.js.

Let's start by creating an object called animals

var animals = {};

Next we will add facts about a few animals. In this case, we will have nest the animals facts within its name. Here's how we will do it.

**DO NOT COPY AND PASTE CODE!**

var animals = {
zebra :{
	 classification : "Mammal",
	 appearance : [ "White with black stripes", "4 legs", "Looks like a donkey"],
	 habitat : "Grasslands",
	 lifespan (Years)" : 25,
         diet : "Herbivore",
         friendly : true	    
       }, //remember to separate nested objects with commas
crocodile : {
         classification : "Reptile",
	 appearance : [ "Long, wide mouth with many teeth", "Close relatives 
                        to dinosaurs", "Looks like a big lizard"],
	 habitat : "Grasslands",
	 lifespan : 100,
         diet : "Carnivore",
         friendly : false
};

We can easily add in new facts about another animal.

Let's start by creating a new object for the last animal and add it to our animal object.

var ostrich = { 
classification : "Bird",
appearance : [ "Big, tall bird", "2 legs", "Has a long neck"],	
habitat : "Grasslands",
lifespan : 45,
diet : "Herbivore",
friendly : true
};

Now that we have created a new object, we can add it directly into our collection of fun facts as we did in Lesson 24.3 - Adding Values to an Object .

animals.ostrich = ostrich;

We use the dot notation to create a new key property (in this case the key value is an object), we then assign it to the new object we created.

We often use if statements in our everyday life to make decisions. For example, if it's morning, you wake up and if it is not morning (meaning it's night) you keep sleeping.

If statements require a condition that will return a boolean(true or false), this means the condition will either be arrived at or not. So in the example above, the condition for us to wake up is if it is morning.

if can also be used to check if two or more statements are the same.

Let's see what if statements look like:

if (condition) {
	what to do if condition is true; 
}

Let's replace this with the example above.

if (morning) {
	wake up;
}

To use this if statement we have to write it as code. Let's start by declaring the variables and then typing the if statement.

var morning = true;

if (morning) {
	console.log("Wake up");
}

What do you think will be displayed on the console?

The console will display wake up because the condition is true, therefore, the code within the condition will be executed.

If statements do rely on a boolean directly/indirectly to execute a statement.

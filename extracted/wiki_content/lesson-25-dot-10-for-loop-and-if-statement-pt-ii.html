Let's now nest the for loop within the if statement.

For example, if the person is ready to walk, they can start counting the steps to get to the table.

We can start by using a pop up for the person to decide if he or she is ready to walk. We will use the confirm() pop up. For the person to confirm if they are ready or not.

if(confirm("Are you ready?")) {
}

Now we can nest the for loop we created earlier within the the if statement, which we will place within the curly brackets.

if (confirm("ready?")) {
   for (var steps = 0; steps<= 10; steps++){
       console.log("I am " + steps + " to the table");

       if (steps === 5) {
       console.log("Turn left");
       } //this closes the nested if statement
   } //this closes the for loop
} //this closes the main if statement

Basically, if we confirm that we are ready, by clicking OK, the directions to the table will be displayed, what happens when we are not ready? We can create an else statement for this case.

else {
	console.log("You are not ready!");
}

When we click OK , the console translates that to true and runs the block of code within the if statement. When we click cancel the console translates that to false and will therefore run the else statement.

Now let's join our code and run it all together

if (confirm("Are you ready?")) {
for (var steps = 0; steps <= 10 ; steps++){
	console.log("I am " + steps + " steps to the table");
	
 if (steps == 5) {
 	console.log("Turn left");
       }
    }
}

else {
	console.log("You are not ready!");
}

Instructions

  1. Copy and paste the code above in the  browser console
  2. Press Enter to run the code. A pop up will show then click ok and observe the results in the console.
  3. Copy-paste the code again. This time, when the pop-up shows, click cancel and observe the results in the console

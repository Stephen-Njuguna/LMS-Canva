We can also loop arrays as easily as we did with variables in the lessons before.

We can start by creating an array to hold a list of a menu at a cafe.

var menu = ["sandwich", "coffee","cookie","muffin", "water"];

If we go to the cafe and ask the waiter what they are serving today, we can do this by looping the array using a for loop.

for (var i = 0; i < menu.length; i++) {
	console.log("We are serving " + menu[i]+ " today.");
}

As compared to our previous for loops the condition, in this case, has changed.

As you notice, we have used i as our variable in the condition. This is actually a very common convention in for loops, because i means "index". If you recall, the position in an array is called the index.

The condition i < menu.length is a little bit different from the previous lessons. Before, we used a number as the condition (for example, steps <= 10 In this example, we have used a property instead of a number. In fact, menu.length evaluates as a number, and is the number of items in our array. i is less than the number of items in our menu then the block of code can executed.

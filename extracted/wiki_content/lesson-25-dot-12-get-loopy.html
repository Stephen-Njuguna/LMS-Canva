There are countless more ways to use loops in our code. For instance, we don't really have to start the looping variable from 0, or increment it by 1. The values can always vary.

For example, here is a way to print all the powers of 2 below 10000.

for (var x = 2; x < 10000 ;  x = x * 2) {
    console.log(x);
}

Basically, here we have initialized the variable and assigned it 2, the condition is x (which is equal to 2) is less than 10000. and the increment value is a power of two.

This is what the computer does :

2 x 1 = 2 = x (making 2 the new value of x)

2 x 2 = 4 = x (making 4 the new value of x)

4 x 2 = 8 = x (making 8 the new value of x)

and so on…

Here's one operator we haven't really used, but it will really come in handy in this lesson as it's often used in conditionals.

The Not operator ! is put in front of = or == operator to mean not. For example, 4 != 3 or 4 !==3. We read this as "Four is not equal to 3".

var see = "To look";
var sea = "A water body";

if (see == sea) {
   console.log("They mean the same");
}

In this case see is not equal to see we can easily change that using the ! operator. and if the condition is true, we can display "They sound the same but don't mean the same".

var see = "To look";
var sea = "A water body";

if (see != sea) { 
   console.log("They sound the same but they don't mean the same");
}

we can translate if(see != sea) in normal statements as if see is not equal to sea .

The console will display the code after the condition since see != sea .

Now that we know what happens when it's morning, let's see what will happen when it's not morning.

We will change the Boolean value for the variable morning to false .

var morning = false;

if (morning) {
	console.log("Wake up"); 
}

This time, nothing will be displayed on the console because the condition evaluates to false.

Instruction

  1. Type the code above.
  2. Click run and observe the results in the editor.

Let's take things up a notch. In this lesson, we will compare two numbers, and display the one with the highest value.

We will start by declaring two numbers.

var highest = 20;
var lowest = 4;

We will then state the condition we want to test. In this case, if 20 has a higher value than 4.

var highest = 20;
var lowest = 4;

if (20 > 4){
	console.log(highest); //should display 20
}

We can easily translate the if statement above into a normal everyday statement. Basically, it reads "If 20 is greater than 4, display on the console the highest number".

20 > 4 is a Boolean value that evaluate to true, therefore the code block is executed.

We can also test to see if the numbers are equal to each other or if one is less than the other, less than or equal to the other, greater than or equal to the other. We will explore comparisons like this in more detail as we continue learning about conditionals.

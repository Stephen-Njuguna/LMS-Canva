We can also write if statements using string data types. When using strings, we often use the == sign to compare values. When we use string data types, the values need to evaluate to a Boolean value and that is only done when we use comparison operators. The comparison operators will then let us know if the two values we are comparing are true or false.

Let's declare two variables.

var see = "To look";
var sea = "A water body";

Now let's test if they are the same.

var see = "To look";
var sea = "A water body";

if (see == sea) {
	console.log("They mean the same"); // the console will display undefined
}

In this example, we are telling our computer, "If see and sea are the same thing, log They mean the same to the console." When we run this code, the computer evaluates that see and sea are not the same thing. In other words, see == sea is the same thing as false Because it's not true the computer skips over the code inside the brackets and does not log anything to the console (run this code and you will see that it displays undefined).

Let's see what happens when see == sea evaluates to true .

var see = "To look";
var observe = "To look";

if (see == observe) {
	console.log("They mean the same"); // the console will display "They mean the same"
}

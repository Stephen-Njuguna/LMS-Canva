So far, we're able to tell our computer what to do if something is true. What if we want something else to happen if it's not true?

Going back to our first example, we know we want to wake up if it's morning, but what happens if it's still night? Right now, we don't have any way of telling our computer what to do. Let's change that with a small addition to our code:

var morning = true;
if (morning) {
	console.log("Wake up");
}
else {
	console.log("Keep Sleeping");
}

Now, our computer has these instructions: If it's morning, say, "Wake up." Else, say "Keep sleeping.

Because we already know how the if statement works, let's see how the else statement works.

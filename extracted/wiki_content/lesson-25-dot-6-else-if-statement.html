We're able to make simple decisions now. But what happens when we have more than two options to choose from?

For example, you are at a restaurant and want to order your favorite drink, coffee. If they don't have coffee, then you will order the next best thing, tea. If they don't have tea either, you know that they always have juice available, so you can always order that.

Let's see how this translates into code:

var coffee = false;
var tea = false;


if (coffee) {
	console.log("One coffee, please.");
}
else if( tea){
	 console.log("I'd like a tea.");
}
else {
	console.log("I'll have juice, please.");
}

Using an else if statement, we are able to make as many decisions as we need.

Consider this conversation between the barista and the client.

Client : Good Morning ! Can I have a cup of coffee?

Barista : Oh Sorry, we don't have coffee today.

Client : Bummer ! Can I have tea?

Barista : We don't have that today either.

Client : Can I have juice?

Barista : Oh sorry, we only serve that at noon.

Client: Then what can I have?

Barista: You can try our milkshake

This is exactly how the else if statements work.

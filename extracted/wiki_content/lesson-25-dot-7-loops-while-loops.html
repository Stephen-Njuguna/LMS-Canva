As we have seen, conditionals allow us to run a piece of code one time if a condition is true. Loops on the other hand, allow us to run a piece of code multiple times, depending on whether a condition remains true.

A while loop is the simplest kind of loop. It repeatedly runs a body of code until a particular condition stops being true .

We can start by creating a variable raining and assign it true .

var raining = true;

Now let's create a while loop to tell us that while it's raining, use an umbrella,

var raining = true;

while (raining) {
console.log("Use umbrella");
}

Notice that when you click run the console displays this error Potential infinite loop...

This is because we haven't specified how many times we would like the output to repeat, the computer will just take it as infinity number of times.

We can exit an infinite loop by using the break statement. We can do this using the if statement and a comparison operator. We will go deeper into this further in the lesson.

Another set of loops is the for loop. To explain how they work, we can use a simple walking analogy where we count the number of steps we take. Let's say it takes 10 steps to get from the seat to the table. Before we start walking to the door, we will have taken 0 steps. As we start walking,the number increases by 1 and so on for the next steps.

We can write a program that increases the number of steps we take.

for (var steps = 0; steps <= 10; steps++){
console.log("I am " + steps + " to the door");
}

This doesn't make sense to humans but this is how the computer translates it.

Setup var steps = 0; this part is run before the loop is executed, this part is used to create a variable to track the number of times the loop has to run,

Condition steps <= 10 if this part is true, then the body of the loop is executed.

In this case, if the steps are less than or equal to 10, we can repeat the action, which is true, as the variable steps has been set to 0, therefore being less than 10, the looping will stop exactly after 10 steps.

Increment steps++ increases the value of steps my one every time the loop is run.

The process is repeated up to 10 times.

Instructions

  1. Create a javascript file and name it for_loop.js.
  2. Type the code above.
  3. Click run and observe the numbers increase up until 10.

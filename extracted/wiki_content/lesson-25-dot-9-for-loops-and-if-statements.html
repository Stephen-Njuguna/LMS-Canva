We can have for loops and if statements nested within each other.

It is important to learn how to nest if statements and for loops within each other as it allows us to control a certain program, you can set the condition for the loop and the number of times you want it to run if the condition is true .

Let's start with an if statement nested within the for loop.

Using the walking analogy, let's say after the 5th step, you have to turn right to go to the table.

We can translate that into code like this:

for (var steps = 0; steps <= 10; steps++) {
    console.log("I am " + steps + " to the door");
    if ( steps == 5 ) {
       //will log Turn left after the fifth step.
       console.log("Turn left"); 
    } //this bracket closes the if statement
}    //this bracket closes the for loop

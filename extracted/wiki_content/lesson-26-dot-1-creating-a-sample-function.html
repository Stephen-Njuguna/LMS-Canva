We can start by creating a simple function that prints Hello World! .

First, we will start by creating a variable and assigning it to a function.

var greeting = function () {
	console.log("Hello World!");
};

This code creates a new function and saves it in the variable greeting .

Instructions

  1. Create a javascript file and name it functions.js.
  2. Type the code above.
  3. Click run and observe the results. Notice that there is nothing showing on the console. This is because we need to call the function. We shall tackle that in our next lesson.

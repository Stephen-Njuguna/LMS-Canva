To run the code inside a function (the function body). we need to call the function, a function call allows us to display the block of code on the console and also reuse the code in a different part of our program. We will look into this very soon in the lesson.

var greeting = function () {
  console.log("Hello World!");
};

For us to call our function and display it in the console, we will have to type greetings(); or console.log(greetings());` however it is best practice that we use the first.

Here is how our code is going to look like:

 var greeting = function () {
	console.log("Hello World!");
};
greetings();

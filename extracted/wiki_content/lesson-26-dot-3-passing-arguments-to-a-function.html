Every time we call greeting() from our previous lessons it will keep printing the same line over and over again. At some point we may want our functions to be more flexible and reusable, for us to do this we use arguments. It is a value that is passed when the function is called.

In the previous lesson our function had no arguments.

var greeting = function () {
	console.log("Hello World!");
};

Arguments allow us to pass values into a function in order to change the function's behaviour when it's called. Arguments always go between the function parentheses.

It is important to note that the names we give to the arguments are called parameters .

Let's add an argument into our code.

var greeting = function(name) {
  console.log("Hello " + name + "!");
};

We create the function above by assigning it to our variable greeting To call the function, we will have to place the value in parenthesis right after our variable name. This is how we call our function greeting..

greeting("Mary");

The console should log Hello Mary! .

Basically, what just happened was, the argument Mary was passed into name therefore, wherever there is name it will be replaced by Mary. ,

var greeting = function(name) {
  console.log("Hello " + name + "!");
};

greeting ("Mary");

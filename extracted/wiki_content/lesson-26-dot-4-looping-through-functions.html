We can use arguments to loop through functions. We can start by creating a function.

var jumpingJacks = function (numberOfTimes) {
};

Then we can use a for loop to make it repeat several times for the number of jumping jacks we would like to do.

for (var i = 1; i < numberOfTimes; i++) {
	console.log( i + " Jumping Jacks!");
}

We can now call the function as many times as we like, let's say 10 In this case the argument we will pass is 11 because as earlier stated in programming languages we start counting from zero but in this case i is set to 1 therefore the output will only be displayed 9 times, therefore for 10, we can set the number of times to loop the code to 11. ,

var jumpingJacks = function (numberOfTimes) {
for (var i = 1; i < numberOfTimes; i++) {
	console.log( i + " Jumping Jacks !");
}
};

jumpingJacks(11); //this will loop the function and display it 10 times.

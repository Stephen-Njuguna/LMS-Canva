You can pass more than one value into a function using multiple arguments.

To add another argument we enter the other arguments into the parenthesis and separate them by commas.

function (argument1, argument2) {
	console.log("This is my first argument: " + argument1);
	console.log("This is my second argument: " + argument2);
}

We can create function using our previous code on jumpingJacks .

var jumpingJacks = function (numberOfTimes) {
for (var i = 1; i < numberOfTimes; i++) {
   console.log( i + " Jumping Jacks !");
}
};

jumpingJacks(11); //this will loop the function and display it 10 times.

Let's create a second argument.

var jumpingJacks = function (numberOfTimes, whatToDo) {
for (var i = 1; i < numberOfTimes; i++) {
  console.log( i + " " + whatToDo);
}
};

jumpingJacks(11, "Jumping Jacks"); //this will loop the function and display it 10 times.

As you may notice, in this line of code console.log( i + " " + whatToDo); we have " " an empty string, this is so as to put spaces into our code so that the output on the console is not so messy.

If we also check out this line of code jumpingJacks(11, "Jumping Jacks"); we have passed two arguments into numberOfTimes and whatToDo respectively.

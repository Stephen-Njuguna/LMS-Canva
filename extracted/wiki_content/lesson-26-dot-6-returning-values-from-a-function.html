So far we have been printing text to the console using console.log() It's a great way to display values on the console however, we may not be able to use that value later in the program. When you call a function, it returns a value, and you can use that value for the rest of your code. .

This time, instead of using console.log() we will use return here's how:

Let's create a funtion that doubles a number.

var double = function ( number ) {
	return number * 2;
};

We can now double any number we pass through our argument number

var double = function ( number ) {
	return number * 2;
};

double(3);

3 will be passed to number in the parenthesis and then return number 2 which is 6 .

NB: if you don't tell the function to return anything, it will return undefined .

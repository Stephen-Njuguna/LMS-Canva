Now that we are working with functions, we need to learn more about variable scopes.

A variable scope determines the accessibility of variables within a program. There are two types of variable scopes.

  1. Global Scopes
  2. Local Scopes

We have been using the global variables since we learnt how to create variables. Global variables can be accessed at any point of the program, that is, if you create a variable eg:

var x = 10;

it can be used anywhere in your program as long as you use x to call the variable. Therefore, meaning it has a global scope.

A local variable is can only be accessed where they have been created, for instance, if we declare a variable within a function like so:

var car = function (model, numberPlate) {
	var wheels = 4; //this is a local variable
	console.log( "I drive a " + model +  "with a number plate of  " + numberPlate + " and it has " + wheels 
	+ " wheels.");
	
};

car ("Toyota", "KBP 123");

In this case, var wheels = 4; is a local variable and can only be accessed by the function when it is called.

If we create another function in our program and try to access the local scope variable in the car function, we will get an error in the console. Let's try it out.

var car = function (model, numberPlate) {
  var wheels = 4; //this is a local variable
  console.log( "I drive a " + model +  "with a number plate of " + numberPlate + " and it has " + wheels
  + " wheels.");
};

var bicycle = function (model, numberPlate) {

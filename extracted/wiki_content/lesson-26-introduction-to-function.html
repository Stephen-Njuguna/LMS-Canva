A function is a collection code that can be reused. Functions allow us to run the same piece of code from multiple places in a program without having to type the code repeatedly.

They are called functions because they perform a specific action, easy right? One function we have already interacted with is the alert() function, we used this to display the alert box and send a specific message to the user.

Basic anatomy of a function

A function looks like this:

function () {
console.log("Do something")
}

We use the keyword function to initialize a function followed by parenthesis () and the function body which is enclosed in curly brackets {} .

Math.round() returns the value of a decimal number to its nearest integer value.

From our previous exercise of finding the circumference of a circle with a radius of 5.4

console.log(2 * Math.PI _*_ 5.4 );

Our result was 33.929200658769766 which is such a long number, we can round it off to the nearest integer using Math.round().

console.log(Math.round (2 * Math.PI * 5.4 ));

To make our code easily readable we will assign 2 * Math.PI *5.4 to a variable. then finally log the rounded off value to the console.

var circumference = 2 * Math.PI _*_ 5.4 ;
var finalValue = Math.round (circumference) ;

console.log (finalValue);

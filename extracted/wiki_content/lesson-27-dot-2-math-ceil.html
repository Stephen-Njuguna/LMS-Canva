Math.ceil() is a method that rounds up a value to its nearest integer.

var circumference = 2  Math.PI * 5.4 ; //33.929200658769766
var finalValue = Math.ceil (circumference) ; //34

console.log (finalValue);

Instructions

  1. Create a javascript file and name it  math_ceil.js.
  2. Find the circumference of a circle with a radius of 45 and use Math.ceil() to round up the finalValue .
  3. Click run and observe the results in the console.

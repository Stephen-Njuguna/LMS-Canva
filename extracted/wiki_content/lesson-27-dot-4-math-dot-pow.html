Math.pow() is another math method. In the context of Math.pow(x, y) , the console will return the value of x to the power of y.

Take for example you want to find the square of 4:

var square = Math.pow (4 , 2);

console.log(square); //console should log 8

We can also find the cubic value of 4.

var cubic = Math.pow (4, 3);

console.log(cubic);

And the value of 4 to power 15

var power = Math.pow (4, 15);

console.log(power);

Instructions

  1. Create a javascript file and name it  math_pow.js.
  2. Type the code above.

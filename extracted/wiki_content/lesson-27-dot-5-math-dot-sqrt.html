For this lesson, Create a javascript file and name it  math_sqrt.js.

Math.sqrt() is used to find the square root of a number.

var squareRoot = Math.sqrt(64);

console.log(squareRoot); //returns 8

Instructions

  1. Using the Math.sqrt() method, find the square root of 64
  2. Console log the variable squareRoot .
  3. Click run and observe the results in the console.

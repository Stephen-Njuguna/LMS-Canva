Math.random() is used to return a random number between 0 and 1, 0 is part of the values that are returned while 1 isn't.

If we want to display a random number we can do so like this:

var surprise = Math.random();

console.log(surprise);

Numbers between 0 and 1 are quite limiting, what if we want to display random numbers between 1 and 10? We can do this by multiplying Math.random() by 10.

var surprise = Math.random() * 10;

console.log(surprise);

However, the returned values are in decimal points.

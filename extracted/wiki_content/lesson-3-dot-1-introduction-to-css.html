Introduction:

Now that we have learnt how to build websites, let's learn how to style them.

We use CSS to style websites.

CSS stands for Cascading Style Sheets.

HTML controls the structure of a page. CSS controls how a page looks.

The same way we kept html code in a file with the .html extension, all css code is kept in a file with the .css extension. For example, the most common way of naming a CSS stylesheet is style.css

Instructions:

  • Create a folder called introduction-to-css. Inside the folder create 2 files; index.html and style.css.
  • Add the following code to the index.html file
<!DOCTYPE html>
<html>
    <head>
        <title>Introduction to CSS</title>
        <link rel="stylesheet" type="text/css" href="style.css">
    </head>
    <body>
        <h1>I am learning how to make websites pretty</h1>
        <h2>I will learn the following in this lesson</h2>
        <ul>
            <li>Linking a stylesheet</li>
            <li>Selectors</li>
            <li>Color</li>
            <li>Background-color</li>
            <li>Font-family</li>
            <li>Font-size</li>
            <li>Font-weight</li>
            <li>Strong tag</li>
            <li>Em tag</li>
        </ul>
    </body>
</html>
  • Add the following code to the style.css file. Don't worry about understanding what the code does for now, we are going to cover that comprehensively in the coming lessons.
h1 {
  font-family: 'Courier New', 'Sans-Serif';
  color: blue;
  font-size: 28px;
  text-align: center;
}

h2 {
  text-align: center;
  font-family: 'Times New Roman', cursive;
  color: brown;
}

ul {
  list-style-type: none;
}

li {
  color: red;
  font-style: italic;
  text-align: center;
}
  • Run the html code on the browser and see what the code looks like when rendered in a browser
  • Navigate to the style.css file. On line 3, change blue to red.
  • Refesh the page where the code was rendered before in the browser. Notice what has changed

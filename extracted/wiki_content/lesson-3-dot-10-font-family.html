Introduction

We use the font-family property to change the font of text in our HTML.

Just as you can change the font in Microsoft Word, you can do it for HTML documents.

NOTE: We shall enclose the font names in quotes.
E.g:

p {
 font-family: 'Lucida Sans';
}

Instructions

  • Create a new folder and name it font-family. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
    <html>
    <head>
            <title>repl.it</title>
            <link rel="stylesheet" type="text/css" href="index.css">
    </head>
    <body>
        <h1>Font-family</h1>
        <p>
            HTML fonts are divided into six groups.
            These are:
        </p>
            <ol>
                <li>serif</li>
                <li>sans-serif</li>
                <li>monospace</li>
                <li>cursive</li>
                <li>fantasy</li>
                <li>system-ui</li>
            </ol>
        <p>
            These six groups are referred to as generic-names, while the
            fonts in each group are referred to as family-names.
        </p>
    </body>
</html>
  • Run the code on the browser to see the current font of the paragraph.
  • Change the paragraphs' font-family to 'Helvetica'.
  • Refresh the browser tab that your code is running on to see the new font

Introduction

We can change the size of text in HTML elements using the font-size property.

The font-size property takes pixel (abbreviated px) values.

Instructions

  •  Create a new folder and name it font-size. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
  <head>
      <title>font-szie</title>
      <link rel="stylesheet" type="text/css" href="index.css">
  </head>
  <body>
    <h2>Font-size</h2>
    <p>
      Besides pixel values, we can also set the font size using absolute size values relative to the default value. These values are:
    </p>
      <ul>
        <li>xx-small</li>
        <li>x-small</li>
        <li>small</li>
        <li>medium</li>
        <li>large</li>
        <li>x-large</li>
        <li>xx-large</li>
      </ul>
    <p>
      The default font size is medium.
    </p>
  </body>
</html>
  • Run the code on the browser to see the current appearance of our web page.
  • Use the p selector to set the font-size of paragraphs to 30px. Hint: Remember we are doing this in our index.css
  • Refresh the webpage on your browser. What do you notice?

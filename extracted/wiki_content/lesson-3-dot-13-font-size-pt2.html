Introduction

As mentioned in the previous lesson's exercise, we can use absolute keywords to set the size of our font.

These keywords are based on the default font size of medium.

They are:

xx-small, x-small, small, medium, large, x-large, xx-large

We'll use the same code, we worked on in the previous lesson

Instructions:

  • Set the font-size of the heading to large.
  • Set the font size of li elements to small.
  • Set the font size of p elements to medium.

For those who are stuck, your css code should look like this

p{
    font-size: medium;
} 
li{
    font-size: small;
}
h1{
    font-size: large;
}

Introduction

We can make our text italic using the font-style property, like this:

h1{  
  font-style:italic;
}

Instructions

  • Create a new folder and name it font-style. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
  <html>
  <head>
    <title>Font Style</title>
    <link rel="stylesheet" type="text/css" href="index.css">
  </head>
  <body>
    <h1>Font style CSS property</h1>
    <p>The font-style CSS property specifies the font style of text. It can be italic, oblique or normal.</p>
  </body>
</html>
  • Run the code on the browser to see what the page looks like.
  • Make the paragraph italicized.
    • Your css code should look like this
p{

font-style: italic;

}

Introduction

We use the font-weight property to set the boldness of the font.

E.g:

p{
 font-weight: bold;
}

Instructions

  •  Create a new folder and name it font-weight. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
  <head>
    <title>Font weight</title>
    <link rel="stylesheet" type="text/css" href="index.css">
  </head>
  <body>
    <h1>Font weight CSS property</h1>
    <p>The font-weight property sets how thick or thin characters in text should be displayed.</p>
  </body>
</html>
  • Run the code on the browser to see the current appearance of the page
  • Set the font-weight of the paragraph to bold.

Introduction

Using the strong tag, we can bold a few words in an element as opposed to all words when using the font-weight property.

Any text between a set of strong tags will display as bold, even without CSS styling. For example,

<p>This text is <strong>bold</strong>.</p>

will be displayed as:

This text is **bold**.

Instructions

  • Create a new folder and name it HTML _strong_tags. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
  <head>
    <title>Making words bold using HTML strong tags.</title>
    <link rel="stylesheet" type="text/css" href="index.css">
  </head>
  <body>
    <h1>Making certain words bold using using HTML strong tags</h1>
    <p>Using the CSS font-weight property, we can make entire elements bold. However, at times we just want to make a few words in an element bold, for example in a paragraph, something important may be made bold. In this case, strong tags are used to show words that are important.</p>
  </body>
</html>
  • Run the code on the browser to see the current appearance of our webpage
  • In the last sentence, make the word important bold by wrapping it in a strong tag, like this:
...words that are <strong>important</strong>.</p>
  • When you refresh the page on the browser, the word important will now be in bold.

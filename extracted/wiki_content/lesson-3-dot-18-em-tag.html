Introduction

Like the strong tag, em tags are used to indicate emphasis on a few words in an element, as opposed to the font-style property, which emphasizes an entire element. ("em" stands for "emphasis").

Words that go in between em tags show up as italicized when the web page is rendered.

Instructions

  • Create a new folder and name it em_tags. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
  <head>
    <title>Emphasizing words using HTML em tags.</title>
    <link rel="stylesheet" type="text/css" href="index.css">
</head>
  <body>
    <h1>Emphasizing a few words in </h1>
    <p>Emphasis tags are used to emphasize words without using CSS styling. Most browsers will display the Em element as italicized text.</p>
  </body>
</html>
  • As usual; run the code on the browser to see the current appearance of the webpage
  • Emphasize the word emphasize in the first sentence of the p element by wrapping it in em tags like this:
Emphasis tags are used to <em>emphasize</em> words without using CSS styling.

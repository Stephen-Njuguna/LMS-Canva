Introduction

We’ve learned how to style a website using CSS

We started by linking a stylesheet.

Then using type selectors to apply CSS properties

We also used the strong and em elements to show emphasis.

Instructions

  • Create a new folder and name it CSS_review. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
  <head>
    <title>Conclusion - lesson review</title>
    <link rel="stylesheet" type="text/css" href="index.css">
  </head>
  <body>
    <h1>A Couple of Popular Super Markets in Kenya</h1>

    <h3>Nakumatt Super Market </h3>

    <p>Nakumatt was <em>originally</em> called <strong>Nakuru Mattresses</strong> Supermarket</p>

    <img src="https://bit.ly/3prYKX0">

    <h3>Tuskys Supermarket</h3>
    <p>The original name of this supermarket was <strong>Tusker Mattresses</strong> Supermarket</p>
    <img src="https://bit.ly/39o7lEn" >

  </body>
</html>
  • Also, add the following code in the index.css file;
*{
    text-align:center;
}
img{
    height:150px;
}
h3{
    color:red;
    font-weight:bold;
}
h1{
    color:#0907a7;
    font-family:helvetica;
}
p{
    background-color:#f0f0f0;
    border:1px solid black;
    padding:10px;
}
  • As usual, run the code on the browser to see the appearance of the web page
  • Take note of the content in the CSS file. You will be creating a similar collection of CSS properties in the next section.

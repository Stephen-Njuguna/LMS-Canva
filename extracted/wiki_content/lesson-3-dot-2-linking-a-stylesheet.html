Introduction:

In order to style our page with CSS, we first need to link a stylesheet.

A stylesheet is a file that contains the CSS code that styles our web page.

We link the stylesheet file from our HTML file using the <link> tag, like this:

<link rel="stylesheet" type="text/css" href="style.css">

rel="stylesheet" and type="text/css" tells the browser that this link is to a CSS stylesheet.

href="style.css" tells the browser it can find the CSS in a file named style.css.

Instructions:

  • Create a new folder called html_things. Inside the folder, two files; index.html and index.css (notice this time we did not name our css stylesheet style.css. This is just to show you that you can name your css stylesheet whatever you want as long as it has the .css extension).
  • In the index.html file, add the following code;
<!DOCTYPE html>
<html>
    <head>
        <title>Holiday Things</title>
    </head>
    <body>
        <h1>Things to do over the holiday</h1>
        <ol>
            <li>Sleep.</li>
            <li>Sleep a little more.</li>
            <li>Sleep just a little bit more.</li>
            <li>Heck, just keep on sleeping!</li>
        </ol>
    </body>
</html> 
  • Add the following CSS code to the  .css file:
h1 {color: blue;}
  • Can you guess what that line does?
  • In the html file, link our css file by adding this inside the head element:

    `<link rel="stylesheet" type="text/css" href="index.css">

  • Run the code on the browser to see what the CSS code does.

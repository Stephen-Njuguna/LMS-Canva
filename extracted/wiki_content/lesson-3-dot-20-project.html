Instructions:

  • Create a folder called css_project. Inside create 3 files inside the folder. These files are index.html, given.css and style.css.
  • Add the html code provided above to the index.html file
  • Add the css code provided above to the given.css file. Note, the css you are going to write in this exercise will be in the style.css file
  • Run the html code on the browser to see how the provided HTML renders as a webpage; As you can see, the page is not awful, but it's not very interesting either.
  • In the index.html file, link the _given.cs_s file by adding a link tag below the title tag.
  • Now refresh the page on the browser. Notice any difference? The page looks better but there's not a whole lot of difference. 
  • Before you add your own CSS, link the style.css file to the index.html as you did for the given.css file.
  • Now open the style.css file and add the following CSS:

    • Set the background-colour of:

      - `**h1**` to `#d4d7f7`

- `**li**` to `#e8e9f7`

- `**img**` to `#e2ccac`

    • Set the color of:

      - **h1** to #63473e

- **h3** to #6b5f5b

    • Set the font-family of:

      - `**h1**` to `**papyrus**`

- `**h3**` to `**monospace**` (this is generic, so no quotes)

- `**p**` to `**cursive**` (this is generic, so no quotes)

    • Set the font style of **h3** to **italic**

    • Set the font size of **h3** to **x-large**

    • Set the font-weight of p to 600

  • If you have time to spare, go ahead and add your own CSS.

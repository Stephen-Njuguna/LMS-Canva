Introduction

In order to style our HTML, we need a way to select specific HTML elements.

This is important as it enables us to style only the elements we want.

We specify which elements to style using selectors. The most basic selectors are the HTML tags themselves.

CSS properties go inside the curly brackets. They modify appearances of the selected element (for example colour, height, size…).

For example, to select a main heading, we write:

h1 {  
     color: red; 
  }

Note that we do not need the angle brackets in our CSS.

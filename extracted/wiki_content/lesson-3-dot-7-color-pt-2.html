Introduction

Let us make our web page more colorful by changing its texts' color.

Instructions

  • We'll start by creating a new project for this lesson. Create a new folder and name it movies. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>

<html>

  <head>

      <title>Color part 2</title>

  </head>

  <body>

    <li>Watch this movie</li>

    <h3>Spider-Man: Homecoming</h3>

    <p>This is probably one of Marvel's best movies. It's action-packed and one you should definitely check out.<a href="http://imax.or.ke/movies/180">learn more</a></p>

    <li>Watch this one too</li>

    <h3>Tranformers: The Last Knight</h3>

    <p>This will definitely get those of you who have missed the deep voice of Optimus Prime. It's not the best transformers movie, but it's not terrible either. <a href="http://imax.or.ke/movies/181">learn more</a>

    </p>

  </body>

</html>
  • Link the index.css file in the html file with the relevant tag.
  • Change the color of the p elements to #cc00bb.
  • Change the color of the h3 element to red.
  • Change the color of the li elements to #206ebc.

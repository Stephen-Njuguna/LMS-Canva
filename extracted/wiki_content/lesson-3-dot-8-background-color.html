Introduction

We can change the background color of an element using the background-color property.

This changes the color of the area behind the element.

Instructions

  • Create a new folder and name it background_clor. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>

  <html>

  <head>

      <title>Background color</title>

  </head>

  <body>

    <h1>Background color</h1>

    <p>A CSS property used to alter the color of the area behind an element

    </p>

    <p>

      To help you visualize the background of elements, we have added a border around all the elements in this page.

    </p>

    <p><a href="https://developer.mozilla.org/en-US/docs/Web/CSS/background-color">learn more</a></p>

  </body>

</html>
  • Change the background color of the h1 element to red.
  • Change the background color of the p element to #cacaca.
  • Run the code on the browser and see what it looks like

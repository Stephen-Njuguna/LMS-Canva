Introduction

In the last lesson, we learned about how to embed images into HTML pages, link to other pages or sites and how to add attributes to elements.

In this section, we are going to review those ideas.

We are going to work with this piece of code:

<!DOCTYPE html>
<html>
    <head>
        <link rel="stylesheet" href="index.css">
        <title>HTML review</title>
    </head>
    <body>
            <h2>About UNESCO</h2>
            <p>UNESCO stands for the United Nations Environmental, Scientific and Cultural Organization.</p>
            
            <a target="_blank">UNESCO</a>
                    
            <img src="https://images-na.ssl-images-amazon.com/images/I/71bwNZNFSEL._SL1500_.jpg">
            
    </body>
</html>

Instructions

  1. In the img tag, add a height attribute with a value of 100.

  2. In the a tags, add an href attribute with value https://en.unesco.org.

  3. Run the code in the browser

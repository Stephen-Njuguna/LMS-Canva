Introduction:

So far, we have been using type selectors to select HTML elements.

We can also select elements using Class selectors.

Class ,is an HTML attribute, and different HTML element types can have the same class value so that we can style them all together.

Instructions:

  • Create a new folder and name it class_selectors. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <title>Kijabe County Things</title>
        <link rel="stylesheet" href="index.css">
    </head>
    <body>
        <h1>The pine trees of the world.</h1>
        <h2>Featuring Kijabe</h2>
        <p class="article summary">
            Pine trees belong to a family of trees called <strong>conifer</strong>.
        </p>

        <h2>Geographical Distribution</h2>
        <p id="pine">
            Most regions of the Northern hemisphere host some native species of pines. <a class="note" href="https://en.wikipedia.org/wiki/pine">More info</a>. This doesn't mean that pine trees do not grow in the southern hemisphere.<br>
            Take <em>Kijabe</em> for example.
        </p>

        <h2>Why Kijabe</h2>
        <p>
            Kijabe is in the Sounthern Hemisphere, but has a diverse population of pine trees.
        </p>
        <h4>Is this weird?</h4>
        <p class="short-note">Not exactly.</p>
        <p class="article">
            Weird explanation: Geographically speaking, the earth rotates on a tilted axis, which means that for almost half of the day, Kijabe is in the Northern Hemisphere (at least if we consider the cosmic plane).
        </p>
        <p>
            Really, though, we started by saying that <a href="#pine">most pine trees grow on the Northern Hemisphere</a>. But does not mean that no pine trees grow in the southern hemisphere.
        </p>

    </body>
</html>
  • Add the following css code to the index.css file
body{
  margin:0 auto; padding:8px;
  text-align: center;
  background-color: rgb(240,250,240);
  display: block;
}
.article{
  line-height: 1.4em;
  font-family: Trebuchet MS;
  color: blue;
  border: 1px solid green;
  padding: 10px;
  background-color: rgb(250,250,250)
}
  • Run the code on the browser to see the current appearance of our webpage.

  

  • Notice that the p element has a class attribute whose value is article
  • Add a class attribute to the second and third p element with value article and refresh the webpage. Notice that the second and third p element is now styled as the first one, because they are of the same class.

Introduction:

HTML elements can belong to more than one class, eg.

<p class=”center description article”> The pine trees of Kijabe are one of the oldest in Kenya. </p>

Elements that have more than one class name will be styled according to the style rules of the individual classes combined.

Note: we'll still use the same code that we used in the previous lesson

Instructions:

  • In the Html code, add class ="center" to the last <p> element.
  • In the css file, select elements of class name center and add a color:blue; text-align:center CSS property
  • Select elements of class name description and add a border:1px solid green;CSS property
  • Refresh the page on the browser. Elements that belong to both classes will have a green border, and blue text color

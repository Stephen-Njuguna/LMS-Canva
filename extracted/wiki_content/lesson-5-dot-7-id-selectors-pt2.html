Introduction:

HTML elements can have both class and id attributes simultaneously.

Style rules in the class and id selectors are both applied.

Below, we will style the second paragraph differently from the rest to show that it is a quote.

Instructions:

  • Add an id attribute with value quote to the first paragraph
  • In the stylesheet, add an id selector for #quote
  • In the id selector, add a padding of 20px, line-height of 0.7em and font-style of italic.
  • Refresh the page to see the new appearance of the page.

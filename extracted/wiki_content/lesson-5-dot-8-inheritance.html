Introduction:

HTML elements that are found within other HTML elements are called Child elements.

Parent elements enclose and contain Child elements.

Child elements inherit styles applied to Parent elements. This idea is called Inheritance.

We will apply styles to a parent element which will be inherited by child elements.

Instruction:

  1. Make a body type selector in the stylesheet and add the following properties to it:
color:green;
text-align: center;
padding:10px;
border: 1px solid brown;
background-color:lightgray

  1. Refresh the page to see the updated appearance of the page.

You'll notice that All the elements in the page will have those properties since they are all child elements of the body element.

Introduction:

All child elements automatically inherit styles from their parent elements.

We can, however, override inherited styles in child elements by using type, .class or #id selectors, and adding properties for the desired styling.

Below, all child elements of the body element have blue text. We will override paragraphs to have green text, and headings to be centered.

Instructions:

  1. Inside the body selector, add a color property with value blue.
  2. Refresh the page on the browser to see the current appearance of the page
  3. Make a type declaration for p elements in the stylesheet and add a color property with value green
  4. Additionally, make a class declaration for heading classes and add a text-align property with value center
  5. Refresh the page to see the inherited styles overridden.

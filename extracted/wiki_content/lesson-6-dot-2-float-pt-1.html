Introduction:

  • To float an element to the left or right, we set its float value to left or right.
  • For example, to float an image to the right, we write:
img {
 float: right;
}
  • This would move the image to the left until it is in contact with the edge of its containing border.

Instructions:

  • Create a new folder and name it Float. Inside the folder create the index.html, index.css and style.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" type="text/css" href="index.css">
        <title>Float</title>
    </head>
    <body>
        <div class="left"></div>
        <div class="left"></div>
        <div class="right"></div>
    </body>
</html>
  • Also, add the following css code to the index.css file
body {
  height: 100vh;
}
div {
  margin: 5px;
  width: 200px;
  height: 200px;
}
.left {
  background-color: rgb(252, 6, 2);
}
.right {
  background-color: rgb(10, 252, 1);
}
  • Add your CSS to the style.css file and remember to link it to the index.html file.
  • Float the <div> with the class "left" to the left.
  • Float the <div> with the class "right" to the right.
  • Run the code on your browser. What do you notice about the floated elements?

Introduction:

  • As you may have noticed, setting the clear property to none has no effect, since it is the default value.
  • To actually clear an element, we set the clear property to either left, right.
  • When set to right, the elements cleared elements floated to the right.
  • Likewise, when cleared left, the element clears elements floated left.

Instructions:

  • Create a new folder and name it clear. Inside the folder create the index.html, index.css and style.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" type="text/css" href="index.css">
        <title>Clear</title>
    </head>
    <body>
        <div class="f-right"><p>I am floated right</p></div>
        <div class="c-left"><p>I am cleared left</p></div>
        <div class="c-right"><p>I am cleared right</p></div>
    </body>
</html>
  • Also, add the following css code to the index.css file
div {
  height: 200px;
  width: 200px;
  margin: 5px;
  background-color: rgb(120, 4, 237);
  background-clip: border-box;
  box-shadow: 5px 5px 2em;
  text-align: center;
}

f-right {
  float: right;
}
  • Run the code to see the  initial appearance of the page
  • Add your CSS in the style.css file and remember to link it to the index.html file.
  • Set the value of the clear property for the element with the class c-right to right.
  • Set the value of the clear property for the element with the class c-left to left.
  • Refresh the page to see the changes

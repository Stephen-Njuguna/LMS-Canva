Introduction:

  • We can also clear elements on both right and left by simply setting their clear property to both.

Instructions:

  • Create a new folder and name it clear_pt_2. Inside the folder create the index.html, index.css and style.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" type="text/css" href="index.css">
        <title></title>
    </head>
    <body>
        <div class="right"><p>float: right</p></div>
        <div class="left"><p>float: left</p></div>
        <div class="both"><p>clear: both</p></div>
    </body>
</html>
  • Also, add the following css code to the index.css file 
div {
  background-color: rgb(45, 237, 237);
  width: 200px;
  min-height: 200px;
  margin: 10px;
  text-align: center;
}

.left {
  float: left;
}
.right {
  float: right;
  height: 400px;
}
.both {
  width: 350px;
}
  • Add your CSS to the style.css file and link it to the index.html file.
  • Clear the element with the class both right and left.

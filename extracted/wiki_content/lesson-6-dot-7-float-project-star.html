  • We've provided you with all the html that you need. Feel free to run the code and see how our unstyled page looks like.
    • Below is a review of the page's structure:
    • The entire page is wrapped inside a <main> element.
    • The left side of the document containing the header, date and news content is wrapped inside a <div> element with the class "news".
    • The right column of the page is wrapped inside a <div> element with a class "column".
  • Below is a review of the page's style (this is the style you are going to add in the style.css file :
    • The background color of the entire page (<html>) is rgb(20, 130, 173)

    • The main container (<main>) is styled as follows:

      • `background-color` is `rgb(237, 237, 237)`
      • `overflow` property is `scroll`
      • width is 65%
    • All the images have individual ids. The first image (the one on Trump) has id one and is styled as follows:
      • float: left
      • height: 200 px
      • width: 300px
      • margin: 0 10px 0 0
    • The second (with plastic bags) has the id two and is styles as follows:
      • float: right
      • margin: 10px 0 0 10px
    • The third image has the id three and has a width of 100%
    •  All paragraphs have the following CSS applied:
      • margin-top: 5px;
      • margin-bottom: 10px;
      • font-size: 0.9em;
      • text-align: justify; (this property aligns the text so that paragraphs are aligned along a straight line to the right and left.)
    • The rest of the CSS is provided for you in the index.css file. Feel free to have a look at it. The following elements have been styled for you:
      • header
      • time (this is the day and date below the title )
      • All headings (h1 and h3) 
      • Anchor elements (<a>)

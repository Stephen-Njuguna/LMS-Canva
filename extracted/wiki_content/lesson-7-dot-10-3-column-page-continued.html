• Our page now looks pretty good except for some few areas such as the links in our left column which are not very visible on a blue background.
  • In addition, it is common for link to change their style when you hover the mouse over them. Let's add a few modifications to our links to make them prettier.
  • We'll start by modifying the links in our left column by making use of CSS specificity rules.

Instructions:

  1. Use the following selectors to select only the links in the left column of our page,
#content-1 a:hover {......}
  1. Note that the space between the id and the a selector is required. Now add the following CSS declaration to the above rule:
color: rgb(250, 255, 0);
font-weight: 900;
  1. Now lets style the rest of the links in the right column and the <footer>. We'll use the CSS pseudo-class,
a:hover{.....}
  1. Add the following CSS declaration to the above rule:
font-weight: 900;
font-style: italic;
color: rgb(255, 0, 250);
  1. Refresh the page to see our fully styled web page.
  • Remember that we provided you with some of the CSS that was used to style the page, such as the CSS for the background image of the page.
  • However, the CSS you wrote is the key to making the web page appear as it is.

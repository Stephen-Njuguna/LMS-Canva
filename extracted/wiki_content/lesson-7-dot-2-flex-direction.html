Introduction:

  • The flex-direction property is used to set the direction in which flex items flow within the flex container. It is set on the flex container.
  • Flex-direction can take either of two values, row or column.
  • By default, flex-direction has the value row set on it. When set to row, the flex items flow horizontally and vertically when we set the value to column.

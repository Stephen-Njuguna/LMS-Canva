• Now that we have the basic page layout sorted, let polish it up by styling the three columns on our page.
  • We'll start by applying the styling that we applied uniformly to all columns.

Instructions:

  1. Add your CSS to the style.css file and remember to link it to the index.html file.
  2. Using the class-selector, 'column', apply the following CSS:
padding: 20px;
margin: 10px 10px 10px 0;
  1. Now let's style the first column of our page, id= 'content-1'.
background-color: rgb(81, 130, 255);
display: flex;
flex-direction: column;
justify-content: space-around;
height: 200px;

  1. Refresh the page to see the effect of our added CSS.

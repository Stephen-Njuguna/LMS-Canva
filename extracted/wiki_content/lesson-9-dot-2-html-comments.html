Introduction

In the previous lesson we saw what a comment looks like. In HTML, comments are written with an opening <!-- tag and a closing --> tag. As mentioned in the previous lesson, comments are not executed so we can use them to hide some of our HTML from being rendered.

Instructions:

  • Create a new folder and name it HTML_comments. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title>HTML Comments</title>
    </head>
    <body>
        <div class="heading">
            <h1>No Comments</h1>
        </div>
        <div class="headline">
            <span>
                Following recent investigations, the police are still searching for the nefarious robot burglar <em>(pictured)</em> who has been tied to several         robberies of flash drives and pirated software.
            </span>
        </div>
        <img src="https://3.bp.blogspot.com/-xIq3W1PP4IA/V57ik8z86AI/AAAAAAAAMAs/TKXLi1aimNs12vhizJe8C4UCL64GhtYyACLcB/s640/Johnny52k_g22_v2.jpg"/>
        <p>Now you see me, now you don't</p>  
        <span>Going under the guise of a vacuum cleaner, the highly wanted robot is still very much at large. Any leads to the robot will be highly appreciated by the authorities.
        </span>
    </body>
</html>
  • Also, add the following css code to the index.css file
.heading{
  display: flex;
  flex-direction: column;
}
h1{
  align-self: center;
  padding: 20px;
  font-family: Helvetica;
  text-align: center;
  color: white;
  background-color: black;
  width: 30%;
}
img{
  height: 300px;
  width: 400px;
  float: right;
}
span{
  font-size: 24px;
}
p{
  font-size: 30px;
  color: white;
  font-family: Comic Sans MS;
  background-color: black;
  padding: 20px;
}
  • Run the code on your browser and  to see the rendered page as it is
  • Comment out the <p> tag in the index.html so that it now looks like this:
 <!-- <p>Now you see me, now you don't </p> -->
  • Refresh the page on your browser.  The <p> tag is now not seen in the rendered page.

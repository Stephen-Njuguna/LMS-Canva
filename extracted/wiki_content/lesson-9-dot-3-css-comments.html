Introduction

We have learned how to add comments in HTML and the same can be done in CSS. In CSS, comments are written with an opening /* and a closing */. When we add comments in CSS, the elements to be styled will not be styled. Therefore, comments in CSS would look like this:

...
/*p{ 
     padding: 50px; 
     color: goldenrod;
   }*/
...

Instructions:

  • Create a new folder and name it css_comments. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file.
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title>CSS Comments</title>
    </head>
    <body>
        <p>After having survived the natural calamity in Nyumba Moja, popular local hero, Mark Kamende; <span>commonly referred to as Makmende</span>, has said he has never felt more energetic in his life.
        </p>
        <p>However doctors fear that Makmende has suffered serious head injuries and will not be able to see in full color. He read the following in <span>black and white</span> yet it is clearly not of that color:
        </p>
        <h3>Dear Makmende, this text is not in black and white.</h3>
        <p>Feel free to donate to reviving his sight on <a href="notarealsite.com">This Website</a>
        </p>
    </body>
</html>
  • Also, add the following css code to the index.css file
span{
  background-color: black;
  color: white;
  font-family: Tahoma;
  padding: 3px;
}
p{
  font-size: 24px;
  font-family: Segoe UI;
  border-bottom: 3px solid black;
  padding-bottom: 20px;
}
h3{
  color:#f0f0f0;
  background-color: #33ee33;
  padding: 30px;
}
  • Run the code on your browser to see the rendered page as it is.
  • Comment out the _h3_ selector so that it looks like this:
/*h3{  
     color : #f0f0f0;
     background-color: #33ee33;
     padding : 30px;
    }
*/

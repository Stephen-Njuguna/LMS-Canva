Introduction

In the previous lesson, we saw 2 of the elements used in making HTML tables: <table> and <tr>. In this lesson, we will look 2 other elements: <th> and <td>.

  • <th> (called table header) is used to define the header of column in a table.
  • <td> (called table data) is used to define the data that is input in a table cell.

(A cell is an intersection of a column and a row)

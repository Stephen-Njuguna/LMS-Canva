Introduction

This project is intended to help you practice making HTML tables. Feel free to apply as much styling as you want.

Instructions:

  • Create a new folder and name it html_tables_project. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title>Futwiz</title>
    </head>
    <body>
        <h1>Futwiz</h1>
        <p>
            After a season full of injuries and send-offs, the League has finally come to an end and here are the final standings
        </p>
        <table>
            <!-- remove this comment and insert the rest of the table here -->
        </table>
    </body>
</html>
  • Run the code on your browser to see the rendered page.
  • Create an HTML table to display the following data:
Team Name   Points
  First XI    21
  Chippa Utd  19
  Tanks FC    18
  Winning XI  18

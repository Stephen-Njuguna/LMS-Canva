JavaScript Math Object allows you to perform mathematical tasks on numbers. The math object provides you with properties and methods which make writing code easier.

We can start with a simple exercise that calculates the circumference of a circle with a radius of 7.

The formula of calculating the circumference of a circle is simply 2πr. Where π = 3.14 to 2 decimal places.

  1. Create a javascript file and name it  math_properties.js.

If we were to write a simple program to calculate the circumference of our circle, this is how we would do it:

var radius = 7;
var pie = 3.14;

console.log  (2 * _radius _*_ pie ); //the result should be 43.96

However, considering the fact that we have the Math.PI object, writing the above program is quite tasking.

Math.PI. is a JavaScript object property that logs 3.141592653589793 in the console. As we know 3.14... is the value of PI in math.

Try it, console log Math.PI and click run notice that it returns 3.141592653589793 .

Instead of creating the variables as we did above, we can directly log the formula for finding the circumference of the circle.

console.log( 2 * Math.PI * 7);

Introduction:

In the previous lesson we learned about the CSS box model - dimensions, border, padding, margin - and the span and div HTML elements.

Instructions:

  • Create a new folder and name it css_review. Inside the folder create the index.html and index.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <title>CSS Layouts review</title>
        <link rel="stylesheet" type="text/css" href="index.css">
    </head>
    <body>
        <div class="container">
        
            <h1>The planets of our Solar System.</h1>
            
            <h2>Brief summary</h2>
            <p class="summary article" id="summary">
                The solar system is a gravitationally bound system consisting of the sun and 8 known planets revolving around it.
            </p>

            <h2>Planets</h2>
            <p class="article" id="planets">
                Heavenly bodies revolving around the sun. They all rotate on their own axis at different speeds in an anticlockwise direction, except for venus.
            </p>
                
        </div>
    </body>
</html>
  • Add the following css code to the index.css file
*{

  margin: 0 auto; padding: 10px;

}
  • Run the code on the browser to see the current appearance of the web page.
  • Select h1 and add a border of 1px solid green
  • Add a padding of 20px in the h1 selector
  • Create a div selector and add a margin of 10px, background-color of rgb(250,250,250)

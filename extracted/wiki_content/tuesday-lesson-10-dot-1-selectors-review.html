Introduction

Previously, we learnt how to style HTML elements using their selectors for example a <h1> would be styled using a `h1` selector. An element with the class name `container` would be styled using a `.container` selector. An element with the id `name` would be styled using the `#name` selector.

Instructions:

  • Create a new folder and name it selectors_review. Inside the folder create the index.html and style.css files.
  • Add the following code in the index.html file;
<!DOCTYPE html>
<html>
    <head>
        <meta charset="utf-8">
        <meta name="viewport" content="width=device-width">
        <link rel="stylesheet" href="index.css">
        <title></title>
    </head>
    <body>
        <p>Developing websites has not always been a straight-forward thing, for sure.</p>
        <p>Since the 1990's everyone has had their own opinions about the best approach to it all. Whether it was in the styling or in the mark-up</p>
        <div id="description">How this element is positioned here took more than just one line of code back in my day.</div>
        <p>But we don't need to worry about that no more, history solved that for us, did it not.</p>
    </body>
</html>
  •  Add the following css code to the stlye.css file 
*{
  background-color: black;
  color: white;
  font-size: 24px;
}
  • Run the code on your browser to see the rendered page as it is.
  • In the style.css file, style all the `p` elements using the `p` selector to have the color blue and the `text-align` property set to center.
  • Style the element with an id called 'description' to give it a padding of 15px.

Introduction

Arrays are basically just a list of data values. They can hold any data type, such as strings or numbers.

For example, if you have a bucket list of places you want to go to, an array lets you easily group them together, rather than creating variables for each and every place.

Arrays take you from this:

var bucketList1 = "Morocco";
var bucketList2 = "Cuba";
var bucketList3 = "Kenya";
var bucketList4 = "Tanzania";
var bucketList5 = "South Africa";
var bucketList6 = "Ethiopia';

To this:

var bucketList = ["Morocco", "Cuba", "Kenya", "Tanzania", "South Africa", "Ethiopia"];

Much simpler right?

Arrays are a list of strings or numbers represented in square brackets [] Each item in an array is separated by commas..

Note that we can mix data types in arrays, so you can have numbers and strings.

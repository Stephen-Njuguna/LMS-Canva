As you work in teams or in any organisation, conflicts are bound to arise. So do you deal with these conflicts as they come? Also, how do you make sure that conflicts don't become disruptive?

Hence, today we'll be having a conflict and resolution workshop.  So that we can know how to navigate through conflict.

The workshop will touch on the following areas;

  • How to address conflict using the conflict resolution process
  • How to recognise when a potential conflict needs to be addressed and also how to prevent disruptive conflicts
  • Using conflicts as a way to get stronger.

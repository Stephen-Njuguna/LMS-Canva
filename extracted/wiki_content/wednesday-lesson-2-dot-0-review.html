Instructions:

  • Create a <!DOCTYPE html> element on the first line to declare that we are working with HTML.
  • Create a <html></html> element.
  • Between the opening and closing html tags, add a <head></head> element then a <body></body> element.
  • In the head element, put a title element with the title Review.
  • In the body element, put an h1 element containing the text About me.
  • Add a paragraph element saying 'Here are a few things about me'.
  • Use an unordered list (ul) element to list the following things about yourself:  
    • Your name
    • Your hobby and interest
    • Your spirit animal

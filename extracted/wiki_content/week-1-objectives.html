Welcome to the first week of your amazing journey of becoming a world-class developer. We're really excited that you decided to take this incredible step, you will not regret it.

We'll begin this week by learning about the command line and get comfortable with running simple commands on the terminal like navigating files and directories in your laptop, creating and deleting directories. We'll also explore the building blocks of HTML. Then we'll move on to explore CSS to style our pages. Finally, we'll get to practice using git to store our code on github as well as publish our webpages to github pages. 

By the end of the week, you will be able to;

  1. Create, view and navigate through files and directories using the command line 
  2. Create simple and static HTML pages
  3. Style the static HTML pages using custom CSS rules linked in a stylesheet
  4. Push and track changes made to the webpages to Github using git

Note: Everyone learns at a different pace. Understanding is the most important goal every day. If you feel like you will not be able to complete all of the lessons on a given day, talk to a TM about ways to ensure that you are covering the day's objectives. Always focus on understanding the concepts at hand, not finishing the work as quickly as possible.

At the end of the week, you will be expected to complete an independent project.  Your TM (Technical Mentor) will review the project on the following objectives:

  • Correct use of HTML Elements and tags;
    • p, div, span, header tags, ordered and unordered list tags, img, strong, em
  • Use of custom css file to style your webpage. 
  • Use of at least 4 of the following styling pedagogies
    • selectors
    • box model
    • background color
    • font family
  • Web page is visualing appealing
  • Publish your site to gh-pages
